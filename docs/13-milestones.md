**성능 측정 (2026-09-25, 고양이 86)** — 개발 빌드 `-perflog`(수직 동기화 끔, 10초 창마다 평균·1% 최악 로그) + `-autohost -autostage N`(기지 없이 벽 속 스테이지 N). DEV 패널에 FPS 줄. 이 맥(Apple M5, macOS 개발 빌드 — Windows 목표 기기 아님, 참고용), 벽 속 스테이지 5(방 19, 네트 오브젝트 158~196, 고양이 3):

| 조건 | 평균 | 1% 최악 |
|---|---|---|
| 1920×1080 창, 혼자 호스트 | 3.6ms (275fps) | 7.0ms |
| 2940×1846 전체 화면, 혼자 호스트 | 4.5ms (221fps) | 7.4ms |
| 에디터 호스트와 같은 맥에서 클라로 | 21.6ms (46fps) — 기지 20.9ms와 같음 → 에디터가 GPU를 같이 써서 생긴 값, 게임 부하 아님 |

- 3-3 목표(144fps = 6.9ms)는 평균으로 넉넉히 넘음. 1% 최악이 목표 선 근처 — 윈도우 목표 기기에서 다시 잴 것(사람 확인 항목).
- 다시 잼 (2026-09-25 고양이 112 — 역할 고양이·보물방 불빛·배관 물·지도·오늘의 집 뒤): 1080p 혼자 호스트 스테이지 5(방 11, 네트 오브젝트 115, 고양이 3, 오늘 덫 대방출) 평균 3.86ms(259fps)·1% 7.4~7.9ms — 거의 그대로.
- **달아오름 주의 (2026-09-25 고양이 138)**: `-perflog`는 수직 동기화를 끄고 무제한으로 그려서 이 맥(노트북)이 몇 분 안에 달아올라 느려진다 — 식은 상태 첫 10초 2.5ms(397fps) → 110초 뒤 6.9ms(145fps)로 꾸준히 오르다 멈춤. 게임 안 누수가 아님을 확인: 에디터에서 60초 동안 오브젝트·컴포넌트 수 증가 0, 연달아 띄운 새 프로세스도 첫 창부터 느림(4.1ms)이고 같은 높이(≈5.0ms, 200fps)에서 멈춤. 위 275·259fps는 **식은 상태 첫 창** 값 — 비교는 같은 조건(식은 첫 창끼리, 또는 달아오른 평탄값끼리)으로. 달아오른 평탄값으로도 1080p 스테이지 5 약 200fps.
- 다시 잼 (2026-09-30 고양이 217·218 — 번역·파일 정리 뒤, 달아오른 상태): 1080p 스테이지 5 한국어 4.47ms·영어 4.59ms(번역 비용 없음), 달아오른 범위(4.1~5.0) 안이라 회귀 증거 없음. 식혀도 4.5ms라 프로파일러로 봄(고양이 232): 프레임 4.9ms 중 게임 스크립트 전체 0.23ms, 렌더링 2.0ms, GPU 표시 대기 1.3ms — **병목은 그리기·화면 표시, 게임 코드 아님**.
- 소리 40여 종 넣은 뒤 (2026-09-30 고양이 279): 1080p 스테이지 5(고양이 3·네트 157) 10초 창 4.42·4.46·4.56ms(약 220fps), 1% 최악 8.7~9.4ms — 넣기 전 4.47ms와 같은 범위, 소리 비용 안 보임.
- **GC 할당 (2026-09-30 고양이 324)**: `-perflog` 줄에 "GC 할당 KB/프레임·GC 횟수"를 더함. 1080p 스테이지 5 개발 빌드 약 5.0KB/프레임·10초에 GC 4~5번(평균 5.0ms). 에디터 프로파일러로 PlayerLoop만 보면 가장 큰 건 **개발용 IMGUI 패널 `DevNetHud` 약 3.9KB/프레임**(OnGUI 2.4 + IMGUI 1.5) — 게임 코드(고양이 두뇌 0.28·RunBar 0.17·RunManager 0.17KB)는 작다. 패널은 릴리스에서 닫을 예정(325). 빌드 프로파일러 기록(`-profiler-log-file`)은 이번엔 6MB에서 멈춰 못 씀 — 에디터 프로파일러로 대신.
- **긴 세션 누수 (2026-10-01 고양이 329)**: 성능 줄에 관리 힙·전체 할당·오브젝트 수를 더함. 개발 빌드 혼자 호스트 스테이지 5 `-autowander` 10분(10초 창 60개): 힙 11~12.6MB·전체 153MB·오브젝트 1145·네트 오브젝트 146 **모두 평탄**, 예외 0 → 늘어나는 것 없음(고양이 54의 30분 확인 뒤 기능이 크게 늘어 다시 봄).
