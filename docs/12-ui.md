# 12. UI (W9–10)

## 원칙

- HUD 최소주의 — 정보는 월드에서 읽히게 (고양이 소리, 소음 파문, 쥐구멍 발광). HUD는 보조.
- 전부 EventBus 구독으로 갱신 (02 규칙). UGUI 사용 (UI Toolkit은 팀 학습비용상 제외).
- 폰트: **주아체 (OFL, Google Fonts)** — `Art/Fonts/Jua/Jua SDF.asset` (TMP 동적 아틀라스 1024, 샘플링 48, 패딩 5 = 10%, Clear Dynamic Data On Build). 댕청 톤.
- uGUI 캔버스 기준: Screen Space Overlay, CanvasScaler 1920×1080 · Match 0.5. 텍스트는 전부 TextMeshPro. 자주 바뀌는 숫자는 같은 문자열이면 대입하지 않는다 (캔버스 리빌드 방지).

### 공통 스타일 (2026-09-14, `Data/UI/UiTheme.asset`)

### 와이어프레임 결정 (2026-09-15)

대화창 그림으로 6화면(메인 메뉴·기지 로비·인게임 HUD·일시정지+설정·결과 개편·로딩)을 확정. **제작 순서: 메인 메뉴 → 일시정지·설정 → 결과 화면 개편 → HUD 추가 위젯.**

- 메인 메뉴: 왼쪽 로고 + 버튼 4개(호스트 시작=강조·친구 방 참가·설정·종료), 오른쪽 배경 3D 장면 자리, 아래 버전·연결 상태. 참가는 Steam 로비 전까지 로컬 접속.
- 일시정지(Esc, 게임은 계속 진행): 계속하기·설정·세션 나가기. 설정 패널은 메인 메뉴와 공용(감도·웅크리기 방식·화면 모드/해상도·볼륨 4종·언어).
- 결과 개편: 큰 제목(귀환/전멸) + 수확 수치 + **플레이어별 기여**(집계 신규) + 해금 칩 + 남은 초. 3D 결과 포즈·팀 스크린샷은 P1, 치즈코인 칸은 규칙 확정 전까지 뺌.
- HUD 추가: 팀 상태(좌상단), 토스트(우상단), [E] 홀드 게이지, 로비 인원/초대(좌상단, 기지). 의심 표시는 고양이 작업 때.
- **소모품 칸 없음 — 인벤 슬롯에 합친다** (사용 = 던지기 입력, docs/08). 인벤이 1~4키를 쓰므로 별도 소모품 키를 두지 않음.

Esc로 닫은 프레임은 시선 리그가 같은 Esc로 커서를 다시 풀지 않는다. **닫기 키 = E 또는 Esc** (`UiCommon.ClosePressed`, 열린 뒤 0.2s 유예) — 에디터 Game 뷰는 Esc에 커서 잠금을 스스로 풀고 코드로 다시 잠가도 Game 뷰 클릭 전엔 안 잠기므로, 에디터에선 E로 닫아야 바로 조작이 이어진다 (빌드는 Esc도 유지 — 2026-09-15 macOS 개발 빌드에서 Esc 닫기 후 바로 조작 확인). E로 닫을 때 그 E를 계속 누르고 있으면 상호작용이 다시 열던 문제 → 상호작용은 **새로 누른 E**로만 시작하고 패널이 닫힌 프레임은 무시(`InputFocus.PanelClosedThisFrame`). 커서가 풀린 채(메뉴 없음)면 HUD에 "화면을 클릭하면 다시 조작" 안내(`UI/CursorHintWidget`) + **게임 화면 클릭으로 재잠금** — DEV IMGUI 패널 영역 클릭은 제외. Player는 UI 타입을 모르고 Core 플래그만 읽는다 (규칙 3). 도감은 ScrollView(ScrollRect > Viewport(Mask) > Content(VLG+ContentSizeFitter)).

## 화면 플로우

```
MainMenu ── 호스트 시작 ──▶ Hub(로비)
    │        └ 참가(스팀 초대/친구 목록) ─▶ Hub
    ├ 설정 / 종료
Hub ── 레버 ──▶ 로딩(팁 문구) ──▶ InRun HUD
InRun ──▶ ResultScreen(오버레이) ──▶ Hub
ESC ──▶ PauseMenu (게임은 계속 돈다 — 멀티) : 계속/설정/세션 나가기
```

## ResultScreen (런 결과 — 스크린샷 바이럴 지점)

- 귀환/전멸 연출 큰 타이틀 ("무사히 이사 완료!" / "고양이 밥이 되었다...")
- 존 수·총 가치·획득 코인, 플레이어별 정산 기여("오늘의 일꾼" 왕관), 새 도감·도전과제.
- **팀 스크린샷 버튼**: 4마리가 결과 포즈로 서 있는 장면 캡처 → 클립보드 (SNS 공유 유도, P1).

## 설정 (PauseMenu > Settings)

감도, 웅크림 토글/홀드, 화면 모드, 해상도, 볼륨(마스터/SFX/BGM/보이스), 언어(ko/en 준비 — 텍스트는 처음부터 LocalizationTable SO로).

## LobbyUI (Hub 오버레이)

- 좌상단: 현재 인원/4, 스팀 초대 버튼(OpenInviteOverlay), 방 공개 설정(친구만/초대만).
- 레버 위 월드 텍스트: "출발 (호스트만)".
