# 12. UI (W9–10)

## 원칙

- HUD 최소주의 — 정보는 월드에서 읽히게 (고양이 소리, 소음 파문, 쥐구멍 발광). HUD는 보조.
- 전부 EventBus 구독으로 갱신 (02 규칙). UGUI 사용 (UI Toolkit은 팀 학습비용상 제외).
- 폰트: **주아체 (OFL, Google Fonts)** — `Art/Fonts/Jua/Jua SDF.asset` (TMP 동적 아틀라스 1024, 샘플링 48, 패딩 5 = 10%, Clear Dynamic Data On Build). 댕청 톤.
- uGUI 캔버스 기준: Screen Space Overlay, CanvasScaler 1920×1080 · Match 0.5. 텍스트는 전부 TextMeshPro. 자주 바뀌는 숫자는 같은 문자열이면 대입하지 않는다 (캔버스 리빌드 방지).

### 공통 스타일 (2026-09-14, `Data/UI/UiTheme.asset`)

- 톤: 쥐구멍·창고 느낌의 따뜻한 갈색 패널 + 노랑 강조.

### 와이어프레임 결정 (2026-09-15)

대화창 그림으로 6화면(메인 메뉴·기지 로비·인게임 HUD·일시정지+설정·결과 개편·로딩)을 확정. **제작 순서: 메인 메뉴 → 일시정지·설정 → 결과 화면 개편 → HUD 추가 위젯.**

- 메인 메뉴: 왼쪽 로고 + 버튼 4개(호스트 시작=강조·친구 방 참가·설정·종료), 오른쪽 배경 3D 장면 자리, 아래 버전·연결 상태. 참가는 Steam 로비 전까지 로컬 접속.
- 일시정지(Esc, 게임은 계속 진행): 계속하기·설정·세션 나가기. 설정 패널은 메인 메뉴와 공용(감도·웅크리기 방식·화면 모드/해상도·볼륨 4종·언어).
- 결과 개편: 큰 제목(귀환/전멸) + 수확 수치 + **플레이어별 기여**(집계 신규) + 해금 칩 + 남은 초. 3D 결과 포즈·팀 스크린샷은 P1, 치즈코인 칸은 규칙 확정 전까지 뺌.
- HUD 추가: 팀 상태(좌상단), 토스트(우상단), [E] 홀드 게이지, 로비 인원/초대(좌상단, 기지). 의심 표시는 고양이 작업 때.
- **소모품 칸 없음 — 인벤 슬롯에 합친다** (사용 = 던지기 입력, docs/08). 인벤이 1~4키를 쓰므로 별도 소모품 키를 두지 않음.

### 구현 현황 (2026-09-14)

- **MainMenu (2026-09-15)** — `Prefabs/UI/MainMenu.prefab` + `UI/MainMenuController.cs`, MainMenu 씬에 배치(+ 단색 MenuCamera). 왼쪽 로고(88)·부제·버튼 4개(호스트 시작 Accent / 친구 방 참가·설정·종료 Secondary)·상태 문구, 오른쪽 배경 장면 자리(Row), 아래 버전·"로컬 모드 (Steam 연결 전)". 호스트 → `NetworkLauncher.StartHostAsync` 후 Hub 로드. 참가 → 로컬 127.0.0.1, 실패하면 트랜스포트 내부 사유 대신 "호스트를 찾지 못했어요…"(DangerText) + 상태 Lobby→MainMenu 복구 + 버튼 재활성. 참가 연결 시도는 10회×0.5초(≈5초, `NetworkLauncher`). 설정은 다음 단계 공용 패널 연결 전까지 안내 문구. DEV 넷 패널은 접속 전엔 안 그림(세션 중 정보·Shutdown만).

- **Hud (루트)** — `Prefabs/UI/Hud.prefab` + `UI/HudController.cs`. 소유 플레이어의 CarryHud가 스폰 시 생성·DontDestroyOnLoad·Bind(운반·스태미나)·디스폰 시 파괴. Overlay 캔버스 1920×1080(sortingOrder 10) 아래: RunBar·StaminaRing(중첩 프리팹 = 하위 캔버스, 리빌드 분리) / Aim(조준점·던지기 게이지·집기 안내, 메뉴 패널이 열리면 숨김) / SlotsArea(인벤 슬롯) / ResultArea(결과 패널). 결과 화면 중엔 Aim·Slots·RunBar 숨김. **IMGUI는 DEV 넷 패널만 남음** (CarryHud의 OnGUI 제거).
  - 위젯 스크립트는 항상 켜진 부모에 두고 표시 대상 오브젝트만 켜고 끈다 (자기 위를 끄면 Update가 멈춰 다시 못 켬).
  - 중첩 캔버스 프리팹 루트는 스케일 1·전체 스트레치로 둔다 — 단독 루트 캔버스로 저장했던 프리팹은 스케일 0이 남아 안 보였음.
- **InventorySlotsWidget / InventorySlotView** — 하단 중앙, 칸 수는 SlotCount(2~4)를 따라 템플릿 복제. 선택 칸 Accent 테두리, 대형 끌기 중 흐리게(0.4).
- **InteractPromptWidget** — 조준점 30px 아래, 집기·같이 들기·자리 없음·내려놓기·던지기 안내. 글자 길이에 맞춰 상자 늘어남.
- **ThrowGaugeWidget** — 조준점 오른쪽 47px, 18×74 세로 채움.
- **ResultPanelWidget** — 귀환/전멸 패널 560폭: 제목 띠(Title) / 쥐구멍+들고 온 것 / 이번 수확(AccentText·Heading) / 누계 / 남은 초(Small). 내용은 이전 IMGUI와 동일 — 새 디자인은 와이어프레임 단계.
- **RunBar** — `Prefabs/UI/RunBar.prefab` + `UI/RunBar.cs`. Hud 안의 하위 캔버스. NetworkVariable 읽기 전용 (RunManager·DeparturePad) — 적립 이벤트는 호스트에서만 나므로 StashedValue 변화로 "+N" 감지. 기지: 집합 a/b·출발 카운트다운·누계 / 스테이지: 출발 대기·쥐구멍·누계·+N·귀환 집합·귀환 카운트다운. 결과 화면 중 숨김.
- **StaminaRing** — `Prefabs/UI/StaminaRing.prefab` + `UI/StaminaRing.cs`. 화면 중앙 84px 링(조준점 둘레), 스프라이트는 코드로 만든 흰 고리 `Art/Textures/UI/Ring.png`(256px, 두께 30) + Image Filled Radial360(위에서 시계방향) + 검은 Outline(밝은 하늘 배경 대비). 뒤에 반투명 검은 트랙 — 지치면 트랙이 빨갛게 (채움이 0이라 링 색으로는 안 보임). PlayerStamina(로컬)를 읽기만 함. 줄기 시작하면 페이드 인(8/s), 가득 찬 뒤 0.6s 지나 페이드 아웃(2.5/s). 색: 보통 흰색 / 25% 이하 주황 / 지침(0·헐떡임, `IsExhausted`) 빨강. 메뉴 패널·결과 화면 중 숨김. 캔버스 sortingOrder 5 (RunBar 10·패널 20 아래). CarryHud가 RunBar와 같이 생성·파괴.
- **ShopPanel** — `Prefabs/UI/ShopPanel.prefab` + `UI/ShopPanel.cs`·`ShopRow.cs`. 자판기(VendingMachine)가 열어준 클라에서만 생성. 창 760×560 중앙, 행 = 이름·설명 / Lv a/b / 가격 버튼(부족·MAX면 비활성). EventSystem 없으면 스스로 만든다 (InputSystemUIInputModule).
- **MirrorPanel / CodexPanel** — 같은 패턴 (Dim → Window → VerticalLayout, 닫기 버튼·Esc). 공통은 `UI/UiCommon`(EventSystem 보장).
- **패널 열림 = 입력 포커스** (`Core/InputFocus`, 2026-09-14): 패널이 열면 커서 해제 + 이동·점프·웅크림·시선·E 상호작용·집기·슬롯 키 정지, 닫으면 잠금. Esc로 닫은 프레임은 시선 리그가 같은 Esc로 커서를 다시 풀지 않는다. **닫기 키 = E 또는 Esc** (`UiCommon.ClosePressed`, 열린 뒤 0.2s 유예) — 에디터 Game 뷰는 Esc에 커서 잠금을 스스로 풀고 코드로 다시 잠가도 Game 뷰 클릭 전엔 안 잠기므로, 에디터에선 E로 닫아야 바로 조작이 이어진다 (빌드는 Esc도 유지 — 2026-09-15 macOS 개발 빌드에서 Esc 닫기 후 바로 조작 확인). E로 닫을 때 그 E를 계속 누르고 있으면 상호작용이 다시 열던 문제 → 상호작용은 **새로 누른 E**로만 시작하고 패널이 닫힌 프레임은 무시(`InputFocus.PanelClosedThisFrame`). 커서가 풀린 채(메뉴 없음)면 HUD에 "화면을 클릭하면 다시 조작" 안내(`UI/CursorHintWidget`) + **게임 화면 클릭으로 재잠금** — DEV IMGUI 패널 영역 클릭은 제외. Player는 UI 타입을 모르고 Core 플래그만 읽는다 (규칙 3). 도감은 ScrollView(ScrollRect > Viewport(Mask) > Content(VLG+ContentSizeFitter)).
- 나머지 위젯(조준점·프롬프트·인벤 슬롯·결과 패널)은 아직 CarryHud의 IMGUI — 순차 이전. 인벤 슬롯은 SlotCount를 읽어 3·4칸도 그린다.

## 화면 플로우

```
MainMenu ── 호스트 시작 ──▶ Hub(로비)
    │        └ 참가(스팀 초대/친구 목록) ─▶ Hub
    ├ 설정 / 종료
Hub ── 레버 ──▶ 로딩(팁 문구) ──▶ InRun HUD
InRun ──▶ ResultScreen(오버레이) ──▶ Hub
ESC ──▶ PauseMenu (게임은 계속 돈다 — 멀티) : 계속/설정/세션 나가기
```

## ResultScreen (런 결과 — 스크린샷 바이럴 지점)

- 귀환/전멸 연출 큰 타이틀 ("무사히 이사 완료!" / "고양이 밥이 되었다...")
- 존 수·총 가치·획득 코인, 플레이어별 정산 기여("오늘의 일꾼" 왕관), 새 도감·도전과제.
- **팀 스크린샷 버튼**: 4마리가 결과 포즈로 서 있는 장면 캡처 → 클립보드 (SNS 공유 유도, P1).

## 설정 (PauseMenu > Settings)

감도, 웅크림 토글/홀드, 화면 모드, 해상도, 볼륨(마스터/SFX/BGM/보이스), 언어(ko/en 준비 — 텍스트는 처음부터 LocalizationTable SO로).
