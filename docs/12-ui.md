# 12. UI (W9–10)

## 원칙

- HUD 최소주의 — 정보는 월드에서 읽히게 (고양이 소리, 소음 파문, 쥐구멍 발광). HUD는 보조.
- 전부 EventBus 구독으로 갱신 (02 규칙). UGUI 사용 (UI Toolkit은 팀 학습비용상 제외).
- 폰트: **주아체 (OFL, Google Fonts)** — `Art/Fonts/Jua/Jua SDF.asset` (TMP 동적 아틀라스 1024, 샘플링 48, 패딩 5 = 10%, Clear Dynamic Data On Build). 댕청 톤.
- uGUI 캔버스 기준: Screen Space Overlay, CanvasScaler 1920×1080 · Match 0.5. 텍스트는 전부 TextMeshPro. 자주 바뀌는 숫자는 같은 문자열이면 대입하지 않는다 (캔버스 리빌드 방지).

### 구현 현황 (2026-09-14)

- **RunBar** — `Prefabs/UI/RunBar.prefab` + `UI/RunBar.cs`. 소유 플레이어의 CarryHud가 스폰 시 생성·DontDestroyOnLoad·디스폰 시 파괴. NetworkVariable 읽기 전용 (RunManager·DeparturePad) — 적립 이벤트는 호스트에서만 나므로 StashedValue 변화로 "+N" 감지. 기지: 집합 a/b·출발 카운트다운·누계 / 스테이지: 출발 대기·쥐구멍·누계·+N·귀환 집합·귀환 카운트다운. 결과 화면 중 숨김.
- **ShopPanel** — `Prefabs/UI/ShopPanel.prefab` + `UI/ShopPanel.cs`·`ShopRow.cs`. 자판기(VendingMachine)가 열어준 클라에서만 생성. 창 760×560 중앙, 행 = 이름·설명 / Lv a/b / 가격 버튼(부족·MAX면 비활성). EventSystem 없으면 스스로 만든다 (InputSystemUIInputModule).
- 나머지 위젯(조준점·프롬프트·인벤 슬롯·결과 패널)은 아직 CarryHud의 IMGUI — 순차 이전. 인벤 슬롯은 SlotCount를 읽어 3·4칸도 그린다.

## HUD 구성 (HudController + 하위 위젯)

| 위젯 | 내용 | 데이터 소스 |
|---|---|---|
| RunBar (상단 중앙) | 쥐구멍 적립액 + 누계 + 귀환 집합 인원 a/b. 적립 순간 +N 팝, 집합 시 귀환 카운트다운 | RunManager NetworkVariable |
| StaminaRing (십자선 주위) | 소모 시에만 페이드 인 | PlayerStamina (로컬) |
| CarryInfo (하단) | 든 아이템 아이콘·가치·"무거움!" 경고 | CarriedItemNetId |
| InteractPrompt | "[E] 구출하기" + 홀드 게이지 | PlayerInteractor |
| SuspicionIndicator | 나를 의심 중인 고양이 방향 화살표 + ?/! | CatBrain.TargetClientId |
| ConsumableSlots (하단 좌) | 소모품 2칸 (1·2키) | 인벤토리 |
| TeamStatus (좌상단) | 동료 얼굴 아이콘 + 상태(다운=해골, 속박=끈끈이) | PlayerCondition |
| Toast | 도감·도전과제 해금 알림 | EventBus |
| PingMarker | 월드 스페이스 3s 마커 (벽 뒤 투시 아이콘) | Ping RPC |

## 화면 플로우

```
MainMenu ── 호스트 시작 ──▶ Hub(로비)
    │        └ 참가(스팀 초대/친구 목록) ─▶ Hub
    ├ 설정 / 종료
Hub ── 레버 ──▶ 로딩(팁 문구) ──▶ InRun HUD
InRun ──▶ ResultScreen(오버레이) ──▶ Hub
ESC ──▶ PauseMenu (게임은 계속 돈다 — 멀티) : 계속/설정/세션 나가기
```

## ResultScreen (런 결과 — 스크린샷 바이럴 지점)

- 귀환/전멸 연출 큰 타이틀 ("무사히 이사 완료!" / "고양이 밥이 되었다...")
- 존 수·총 가치·획득 코인, 플레이어별 정산 기여("오늘의 일꾼" 왕관), 새 도감·도전과제.
- **팀 스크린샷 버튼**: 4마리가 결과 포즈로 서 있는 장면 캡처 → 클립보드 (SNS 공유 유도, P1).

## 설정 (PauseMenu > Settings)

감도, 웅크림 토글/홀드, 화면 모드, 해상도, 볼륨(마스터/SFX/BGM/보이스), 언어(ko/en 준비 — 텍스트는 처음부터 LocalizationTable SO로).

## LobbyUI (Hub 오버레이)

- 좌상단: 현재 인원/4, 스팀 초대 버튼(OpenInviteOverlay), 방 공개 설정(친구만/초대만).
- 레버 위 월드 텍스트: "출발 (호스트만)".
