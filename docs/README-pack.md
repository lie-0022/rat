# 쥐도 새도 모르게 — 개발 계획 팩 사용법

이 팩은 클로드코드가 Unity에서 기본 로직 전체를 구현할 수 있게 만든 실행 사양서다.

## 시작 순서

1. Unity Hub에서 **Unity 6000.0 LTS(최신 패치) + URP 3D 템플릿** 프로젝트 생성 (이름: RatGame)
2. git init + Unity 표준 .gitignore + Git LFS 설정
3. 이 팩의 `CLAUDE.md`를 프로젝트 루트에, `docs/` 폴더를 통째로 루트에 복사
4. 프로젝트 루트에서 클로드코드 실행 → `docs/14-claude-code-workflow.md`의 **W1 첫 세션 프롬프트** 복붙
5. 이후는 `docs/13-milestones.md`의 태스크 번호 순서로 진행 (공통 프롬프트 템플릿은 14 문서)

## 가장 중요한 것

- **W1–2는 넷코드만 한다** (docs/03). 회색 박스 4인 운반이 되기 전에는 어떤 콘텐츠도 만들지 않는다.
- W2 말 Go/No-Go: docs/03 수용 기준 미달 시 폴백(탑쌓기 싱글) 논의 — 기한을 넘겨 붙잡지 않는다.
- 매주 금요일 4인 플레이테스트, 웃긴 장면은 바로 SNS 개발일지로.

## 팩 구성

- `CLAUDE.md` — 클로드코드용 프로젝트 규칙 (루트 복사용)
- `docs/00~14` — 사양서 15개 (00 목차 참조)
- `kickoff-prompt.txt` — 맨 처음 클로드코드에 넣을 마스터 프롬프트
