### 2-3. 고친 버그 (눈에 보이던 것 위주)
- 스테이지 출발이 **유령 연결**(접속하다 끊긴 클라)에 묶여 멈추던 것 → 20초 정리 + 로드 판정을 접속 중인 사람만으로(멈춘 클라 120초 → 30초).
- **끈끈이 구독 누수** — 다음 스테이지에서 구출할 때 예외.
- **쓰러진 동안 콘솔 오류**가 초당 ~10번(1번째 루프 고양이 46부터 있던 것).
- 동료 화면에서 **쓰러진 몸 털 색**이 기본 팀색으로 나오던 것(U-11에 적음).
- **시작 자리 겹침** — 재접속·실패한 접속 뒤 들어온 쥐가 호스트 자리에 생겨 둘 다 튕겨 기절.
- 매 로드 경고·클라 고양이 NavMesh 오류·창고 전리품 적립 경고 등 **로그 잡음**(개발 빌드에선 오류가 나면 화면에 콘솔이 떠서 확인을 방해).
- F1 꼬리표가 2인 이상 팀 상자를 가리던 것, DEV 패널 "FPS 0".

### 2-4. 검증만 한 것 (코드 변화 없음 또는 작음)
- 통째 소크 **10번**(기지 → 벽 속 1~5 → 엔딩, 2인·4인·10분 배회): 마지막엔 **오류·경고까지** 호스트·클라 0.
- 문서 수용 기준 체크: 털실 구매→사용(docs/08, 고양이 90) + 막바지 6개 — 4인 핑·팀 상태 / 4인 라운드 루프(docs/09·11) / UI 누수 없음 / 이동 코스(경사·턱·웅크림 터널) / 상대 이동 보간·점프·웅크림 동기화. 남은 건 대부분 사람 몫(MPPM 창·스팀 2대)이나 판단 대기.
- 성능: 스테이지 5 혼자 호스트 259~275fps(이 맥, 참고용).
- 스테이지별 위험도(배회 쥐): 1~3은 전멸 없음, 고양이 3마리부터 1~2분 → 판단 7 참고.
- 빌드 클라 첫 접속 실패 = 에디터가 호스트일 때만(빌드끼리는 첫 시도에 붙음) — 실제 게임 해당 없음.

### 2-5. 확인을 돕는 도구
- **F4 개발용 확인 메뉴**(U-00): 집주인 이벤트 바로 켜기, 기능 자리로 가기(보물방·배관·판매대·문지기 초소·순찰꾼 길·**쥐덫 미끼**), 고양이 불러오기, 쓰러지기/살리기, **오늘의 집 강제**.
- 빌드 옵션: `-autohost -autostage N`(기지 없이 스테이지 N), `-perflog`, `-autojoin`, `-autowander`, `-autoshop`.
- `Tools/RatGame/Test/Create Movement Course` → `Scenes/Test_MovementCourse`(이동 시험 코스).
