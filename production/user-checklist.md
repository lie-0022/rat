# 직접 확인 체크리스트

> 기능마다 **게임 안에서 직접 확인하는 방법**. 확인하면 `[ ]`를 `[x]`로, 이상하면 옆에 적어 주세요.
> 루프가 기능을 하나 끝낼 때마다 여기에 항목을 추가한다 (2026-09-24 사용자 요청 "나중에 다 직접 체크할 수 있도록").
> **어느 루프에서 만든 건지**는 `production/2026-09-25-work-overview.md` — 이번 루프(고양이 62~137) / 루프 사이(쥐 모델·털 색) / 저번 루프(고양이 1~61)로 나눠 U-번호를 적어 둠.
>
> **조작**: 이동 WASD · 달리기 Shift · 웅크리기 Ctrl · 점프 Space · 잡기 좌클릭 · 던지기 우클릭 · 상호작용 E · 찍찍 Q · 핑 F/휠클릭 · **킁킁 R** · **조작 안내 F1** · **지도 Tab**(벽 속)
> **개발용 키**: F3 고양이 상태 표시 · **F4 개발용 확인 메뉴**(호스트 — 집주인 이벤트 바로 켜기, 기능 자리로 순간이동, 고양이 불러오기, 쓰러지기/살리기)
> **시작**: 에디터에서 `Hub` 씬 플레이 → 기지. **새 루프는 목적지 게시판 "벽 속(생성)"** + 출발 발판(스테이지 1~5 → 엔딩). 창고 맵은 "창고", v1 랜덤 맵은 "부엌(생성)". `Stage_Walls` 씬을 바로 플레이하면 스테이지 1(Enter로 출발).
> **빌드로 바로**: `Rat -autohost -unitytransport -autostage 3` = 기지 없이 벽 속 스테이지 3 (문지기·아기 확인용).

## ⏱ 새 루프 빠르게 보기 (약 20분, 혼자)

1. `Hub` 플레이 → 목적지 게시판 E로 **"벽 속(생성)"**(설명 줄 확인, U-111) → 출발 발판.
2. 스테이지 1: 오른쪽 위 **안내 토스트**(U-81), **F1**(U-77), **R 킁킁**(U-76), 방 몇 개 돌고 **Tab 지도**(U-102). 회색 **배관** 지나가 보기(U-79), 안에서 Shift로 뛰면 입구에서 쿵쿵(U-87).
3. 식량을 목적지(주황 방) 창고로 → 할당량 넘는 순간 **"할당량 채움!"**(U-95) → 판매대 E로 **상점**(U-65) → 창고에 서면 다음 스테이지.
4. **F4** → "여기로 가기"로 **보물방**(노란 빛, U-84·88)·**문지기 초소**·**순찰꾼 길**(스테이지 3·5, U-80·92) 확인.
5. F4 → 집주인 **"덫 놓기"·"배관 물"**(U-89·97), **"오늘의 집"** 버튼으로 정전 등(U-106·107).
6. 끝까지 가면 **엔딩 요약**(U-108). 빠르게는 빌드 `Rat -autohost -unitytransport -autostage 5`로 스테이지 5부터.

6. **F4 → 보물방 가기** → 문 밖에서 노란 빛이 문 쪽까지 번짐(U-148). 상점에서 **방울**(60) 사서 다음 맵 고양이에 던지기 → 목 방울·지도 주황 점(U-140).

**2인** (에디터 + 빌드 `Rat -autojoin -unitytransport`, 또는 친구)
