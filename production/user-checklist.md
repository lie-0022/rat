# 직접 확인 체크리스트

> 기능마다 **게임 안에서 직접 확인하는 방법**. 확인하면 `[ ]`를 `[x]`로, 이상하면 옆에 적어 주세요.
> 루프가 기능을 하나 끝낼 때마다 여기에 항목을 추가한다 (2026-09-24 사용자 요청 "나중에 다 직접 체크할 수 있도록").
>
> **조작**: 이동 WASD · 달리기 Shift · 웅크리기 Ctrl · 점프 Space · 잡기 좌클릭 · 던지기 우클릭 · 상호작용 E · 찍찍 Q · 핑 F/휠클릭
> **개발용 키**: F3 고양이 상태 표시 · **F4 개발용 확인 메뉴**(호스트 — 집주인 이벤트 바로 켜기, 기능 자리로 순간이동, 고양이 불러오기, 쓰러지기/살리기)
> **시작**: 에디터에서 `Hub` 씬 플레이 → 기지. 창고 맵은 목적지 게시판 "창고" + 출발 발판, 랜덤 맵은 "부엌(생성)".

## 0. 도구

- [ ] **U-00 개발용 확인 메뉴 (F4)** — 아무 씬 플레이 → F4. 오른쪽에 메뉴, 커서가 풀림. 스테이지에서 "TV 켜기" 등 집주인 이벤트 버튼, "여기로 가기" 버튼이 보이는지. F4·Esc로 닫힘.
  - 내 검증: 창고 맵에서 F4 → 열림·커서 풀림, 가기 대상 15곳(쥐구멍·TV·어둠 구역·창문·끈·후추통·레이저·창고방 문·초인종·물그릇·치즈·숨을 곳·함정·고양이 침대·선반), TV 가기 → 1.6m 앞, 출발 전에도 "TV 켜기" → TV 켜짐·고양이 TV로 감. 에디터·개발 빌드에서만 생김.

## 1. 캐릭터·기지

- [ ] **U-01 쥐 모델** — Hub. 친구(두 번째 창)가 있으면 서로 보기, 혼자면 거울(E)로 내 모습. 회색 털·분홍 귀/코/배/꼬리·눈·수염, 키가 캡슐과 비슷. 1인칭에서 내 몸이 시야를 안 가림. 웅크리면(Ctrl) 모델도 납작.
  - 내 검증: 앞·뒤 렌더, 1.2m·발 바닥, 2인에서 상대 쥐 파랑 팀색.
  - 알려진 것: 뼈대·애니 없음(T자세로 미끄러짐), 쓰러진 몸은 아직 캡슐.
- [ ] **U-02 털 색 — 스킨** — 거울(E) → 스킨 "착용". 털만 바뀌고 분홍 부위·눈은 그대로.
  - 내 검증: 4색 모두 털만 변경, 2인에서 상대 화면 반영.
- [ ] **U-03 털 색 — 팔레트 견본** — 거울 → 아래 견본 16개 중 하나 클릭 → 바로 입음(저장). 다른 사람과 같은 색도 됨.
- [ ] **U-04 털 색 — 슬라이더 실시간 미리보기** — 색상·채도·밝기를 끌면 **거울 속 내 쥐가 바로 그 색**, 아래 "미리보기 중" 안내. "이 색 입기" 안 누르고 닫으면 원래 색으로.
  - 내 검증: #3C00EA 미리보기 스크린샷, 닫으면 복귀·저장 불변, 2인에서 미리보기는 상대에게 안 감.
- [ ] **U-05 털 색 — 색 코드 입력** — 입력칸 클릭 → `#E0457B`(또는 `e0457b`) 입력 → 6자리 되는 순간 슬라이더·거울 반영 → "이 색 입기". 치는 중 E로 창이 안 닫히는지, Esc 한 번은 입력칸만 빠져나오는지.
  - 내 검증: 입력 값 반영·저장·2인 동기화. **실제 키보드 타이핑은 제가 못 해봤음 — 꼭 확인 부탁**.
- [ ] **U-06 목적지 게시판** — Hub 동쪽 벽 게시판 E → "창고" ↔ "부엌(생성)" 바뀜, 화면 위 "목적지 X". 발판 위 카운트다운 중엔 안 바뀜. 귀환 뒤에도 고른 목적지 유지.

## 2. 랜덤 맵 (부엌)

- [ ] **U-07 랜덤 부엌 맵** — 게시판 "부엌(생성)" → 발판 → 방 4~6개가 이어진 회색 맵, 쥐구멍방에서 시작. 전리품·함정·고양이 1마리. 다시 출발하면 배치가 달라짐.
  - 내 검증: 시드 200개 겹침·끊김 0, 2인에서 클라가 바닥 위(낙하 버그 고침), 적립 → 귀환 → 기지.
- [ ] **U-08 부엌 숨을 곳·어둠** — 부엌 맵 모서리에 빈 상자(2명)·장화(1명) → E로 숨기/나오기. 어두운 바닥 판(4×4) 위에선 고양이가 절반 거리에서만 봄(F3로 게이지 확인).
- [ ] **U-09 떨어짐 구조** — (버그 대비 안전망) 맵 밖으로 떨어지면 시작 자리로 돌아옴. 평소엔 안 보이는 게 정상.
- [ ] **U-10 반지 자리** ⏸ — 부엌 맵에서 반지가 고양이 침대 근처(2m)에 있는지. **아직 제가 플레이 확인 전**.

## 2-1. 벽 속 맵 (생성기 v2 — 새 루프)

- [ ] **U-60 벽 속 랜덤 맵** — 기지 게시판을 "벽 속(생성)"까지 돌리고 발판 → 나무 바닥·베이지 벽의 방 10~20개. 출발방(초록 바닥, 문 1개)에서 **문 쪽을 보고** 시작. 방마다 전리품·함정·숨을 곳·어둠 판, 고양이 1마리. 다시 출발하면 모양이 바뀜.
  - 내 검증: 시드 2000개 실패 0·고리 93%, 2인에서 클라 109/109 수신·막음벽 12/12·둘 다 문 쪽(0°).
- [ ] **U-61 두 갈래 길·막다른 방** — 목적지방(주황 바닥)까지 가는 길이 대개 두 개(회색 벽 통로 = 고리를 닫는 파이프). 곁가지 끝은 막다른 방. F4 "쥐구멍"은 이제 **목적지방 창고**로 감.
  - 참고 그림: `production/plans/cat-62/grid_seed1001.png` (위에서 본 모습, 맵 시안과 비교).
- [ ] **U-62 목적지에 모여 끝내기** — 목적지방 창고에 전원이 서면 카운트다운 → 결과 → 기지.
- [ ] **U-63 식량 할당량** — 벽 속 맵 화면 위 `스테이지 1/5   식량 0/150`. 식량(전리품)을 목적지 창고에 내려놓으면 올라감. 모자란 채로 창고에 서면 `식량이 모자라요 — N 더` 안내, 넘어가지 않음. 채우면 `창고에 모이면 다음으로` → 3초 → 기지. 다시 벽 속으로 출발하면 `스테이지 2/5`, 할당량 225. 쓰러져 전멸하면 스테이지 1부터.
  - 내 검증: 1인 막힘·클리어(154 중 150 먹음, 남은 4)·스테이지 2 할당량 225·전멸 초기화, 2인 클라 표시값·막힘·클리어(남은 27).
- [ ] **U-64 스테이지 연속·엔딩** — 할당량을 채워 넘어가면 결과 화면 `스테이지 1 클리어! 가족이 150만큼 먹었어요 — 남은 식량 N` → `N초 뒤 다음 맵으로` → **기지를 거치지 않고 새 벽 속 맵**(모양이 다름) `스테이지 2/5 식량 0/225`. 5번째를 넘기면 `배불리 겨울을 났다!` 엔딩 → 기지. 쓰러져 전멸하면 `굶었다...` → 기지 → 다음엔 스테이지 1부터.
  - 빨리 보는 법: 5스테이지는 길어서, 지금은 한 스테이지씩 확인(엔딩은 제가 강제로 5/5로 만들어 확인함).
  - 내 검증: 1인 연속·엔딩·초기화, 2인 둘 다 새 맵·클라 141/141·클라 표시값.
  - 아직: 스테이지 사이 상점(다음 단계), 엔딩 이야기 문구(기획).
