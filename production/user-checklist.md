# 직접 확인 체크리스트

> 기능마다 **게임 안에서 직접 확인하는 방법**. 확인하면 `[ ]`를 `[x]`로, 이상하면 옆에 적어 주세요.
> 루프가 기능을 하나 끝낼 때마다 여기에 항목을 추가한다 (2026-09-24 사용자 요청 "나중에 다 직접 체크할 수 있도록").
>
> **조작**: 이동 WASD · 달리기 Shift · 웅크리기 Ctrl · 점프 Space · 잡기 좌클릭 · 던지기 우클릭 · 상호작용 E · 찍찍 Q · 핑 F/휠클릭
> **개발용 키**: F3 고양이 상태 표시 · **F4 개발용 확인 메뉴**(호스트 — 집주인 이벤트 바로 켜기, 기능 자리로 순간이동, 고양이 불러오기, 쓰러지기/살리기)
> **시작**: 에디터에서 `Hub` 씬 플레이 → 기지. 창고 맵은 목적지 게시판 "창고" + 출발 발판, 랜덤 맵은 "부엌(생성)".

---

## 0. 도구

- [ ] **U-00 개발용 확인 메뉴 (F4)** — 아무 씬 플레이 → F4. 오른쪽에 메뉴, 커서가 풀림. 스테이지에서 "TV 켜기" 등 집주인 이벤트 버튼, "여기로 가기" 버튼이 보이는지. F4·Esc로 닫힘.
  - 내 검증: 창고 맵에서 F4 → 열림·커서 풀림, 가기 대상 15곳(쥐구멍·TV·어둠 구역·창문·끈·후추통·레이저·창고방 문·초인종·물그릇·치즈·숨을 곳·함정·고양이 침대·선반), TV 가기 → 1.6m 앞, 출발 전에도 "TV 켜기" → TV 켜짐·고양이 TV로 감. 에디터·개발 빌드에서만 생김.

## 1. 캐릭터·기지

- [ ] **U-01 쥐 모델** — Hub. 친구(두 번째 창)가 있으면 서로 보기, 혼자면 거울(E)로 내 모습. 회색 털·분홍 귀/코/배/꼬리·눈·수염, 키가 캡슐과 비슷. 1인칭에서 내 몸이 시야를 안 가림. 웅크리면(Ctrl) 모델도 납작.
  - 내 검증: 앞·뒤 렌더, 1.2m·발 바닥, 2인에서 상대 쥐 파랑 팀색.
  - 알려진 것: 뼈대·애니 없음(T자세로 미끄러짐).
- [ ] **U-02a 걷는 흔들림** — 친구 쥐(또는 거울 속 나)가 걸으면 통통 튀며 좌우로 뒤뚱, 달리면 앞으로 더 기울어짐. 멈추면 숨쉬듯 살짝 부풀었다 줄어듦. 뼈대 없이 모델만 흔드는 거라 어색하면 웃긴 쪽.
  - 내 검증: 1인 걷기 3.6m/s → 좌우 ±9°·앞 8°·튀기 6cm, 멈춤 → 흔들림 0·숨쉬기 ±1.5%. 2인 상대 쥐도 같은 흔들림(`production/plans/cat-71/remote_walk.png`).
- [ ] **U-02 털 색 — 스킨** — 거울(E) → 스킨 "착용". 털만 바뀌고 분홍 부위·눈은 그대로.
  - 내 검증: 4색 모두 털만 변경, 2인에서 상대 화면 반영.
- [ ] **U-03 털 색 — 팔레트 견본** — 거울 → 아래 견본 16개 중 하나 클릭 → 바로 입음(저장). 다른 사람과 같은 색도 됨.
- [ ] **U-04 털 색 — 슬라이더 실시간 미리보기** — 색상·채도·밝기를 끌면 **거울 속 내 쥐가 바로 그 색**, 아래 "미리보기 중" 안내. "이 색 입기" 안 누르고 닫으면 원래 색으로.
  - 내 검증: #3C00EA 미리보기 스크린샷, 닫으면 복귀·저장 불변, 2인에서 미리보기는 상대에게 안 감.
- [ ] **U-05 털 색 — 색 코드 입력** — 입력칸 클릭 → `#E0457B`(또는 `e0457b`) 입력 → 6자리 되는 순간 슬라이더·거울 반영 → "이 색 입기". 치는 중 E로 창이 안 닫히는지, Esc 한 번은 입력칸만 빠져나오는지.
  - 내 검증: 입력 값 반영·저장·2인 동기화. **실제 키보드 타이핑은 제가 못 해봤음 — 꼭 확인 부탁**.
- [ ] **U-06 목적지 게시판** — Hub 동쪽 벽 게시판 E → "창고" ↔ "부엌(생성)" 바뀜, 화면 위 "목적지 X". 발판 위 카운트다운 중엔 안 바뀜. 귀환 뒤에도 고른 목적지 유지.

## 2. 랜덤 맵 (부엌)

- [ ] **U-07 랜덤 부엌 맵** — 게시판 "부엌(생성)" → 발판 → 방 4~6개가 이어진 회색 맵, 쥐구멍방에서 시작. 전리품·함정·고양이 1마리. 다시 출발하면 배치가 달라짐.
  - 내 검증: 시드 200개 겹침·끊김 0, 2인에서 클라가 바닥 위(낙하 버그 고침), 적립 → 귀환 → 기지.
- [ ] **U-08 부엌 숨을 곳·어둠** — 부엌 맵 모서리에 빈 상자(2명)·장화(1명) → E로 숨기/나오기. 어두운 바닥 판(4×4) 위에선 고양이가 절반 거리에서만 봄(F3로 게이지 확인).
- [ ] **U-09 떨어짐 구조** — (버그 대비 안전망) 맵 밖으로 떨어지면 시작 자리로 돌아옴. 평소엔 안 보이는 게 정상.
- [ ] **U-10 반지 자리** — 부엌 맵에서 반지가 고양이 침대 근처(2m)에 한 개. F4 "고양이 침대"로 가서 확인.
  - 내 검증: 시드 3개 모두 1개, 침대에서 1.1~1.4m.

## 2-1. 벽 속 맵 (생성기 v2 — 새 루프)

- [ ] **U-60 벽 속 랜덤 맵** — 기지 게시판을 "벽 속(생성)"까지 돌리고 발판 → 나무 바닥·베이지 벽의 방 10~20개. 출발방(초록 바닥, 문 1개)에서 **문 쪽을 보고** 시작. 방마다 전리품·함정·숨을 곳·어둠 판, 고양이 1마리. 다시 출발하면 모양이 바뀜.

- [ ] **U-63 식량 할당량** — 벽 속 맵 화면 위 `스테이지 1/5   식량 0/150`. 식량(전리품)을 목적지 창고에 내려놓으면 올라감. 모자란 채로 창고에 서면 `식량이 모자라요 — N 더` 안내, 넘어가지 않음. 채우면 `창고에 모이면 다음으로` → 3초 → 기지. 다시 벽 속으로 출발하면 `스테이지 2/5`, 할당량 225. 쓰러져 전멸하면 스테이지 1부터.

  - 볼 것: 배관 입구가 문틈과 구분되는지, 안에서 답답하지 않은지, 들고 있는 큰 물건이 걸리는지(걸리면 웃긴지).
  - 내 검증: 배관에 고양이 길 없음(돌아가는 길 89.5m vs 직선 8m), 고양이는 모든 방 도달, 쥐 통과, 추격 중 배관으로 숨으면 놓침, 2인 입구 모양 같음, 예외 0.

- [ ] **U-80 문지기 고양이** — 벽 속 스테이지 3부터 고양이 한 마리가 **목적지(주황 방) 바로 앞 방**에서만 어슬렁거림. 털실·레이저로 끌어내면 약 30초 틈이 생김. 목적지 문이 둘이면 다른 문으로 돌아가도 됨.
  - 확인 요령: 스테이지 3 이상에서 F4 "여기로 가기" → 목적지 쪽으로 가 보기 / 상점에서 털실을 사서 다음 맵에서 써 보기.
  - 내 검증: 60초 동안 문지기 초소 10m 안 100%(다른 고양이 0%), 털실로 20m 끌어냄 → 39초 뒤 복귀, 아기와 같이 나와도 어른이 문지기, 예외 0.

- [ ] **U-81 스테이지 안내** — 벽 속 맵이 열리면 오른쪽 위에 6초 동안: "스테이지 n/5 — 식량 N 모아 목적지(주황 방)로" + 그 스테이지에 있는 것(문지기·아기 고양이). 스테이지 1엔 "회색 배관은 쥐만 · R 킁킁" 팁.
  - 내 검증: 스테이지 1·3·5 문구, 우상단 토스트 화면 확인, 2인 클라도 같은 안내, 예외 0.

- [ ] **U-82 문지기는 푸른 회색** — 문지기 고양이는 푸른 회색(러시안 블루)이라 한눈에 구분됨. F3 고양이 정보에 "문지기". 다른 고양이는 문지기 색으로 안 나옴.
  - 내 검증: 스테이지 4 호스트·클라 둘 다 "문지기" 성격, 화면 색 확인, 예외 0.

- [ ] **U-84 막다른 보물방** — 벽 속 맵마다 출발에서 가장 먼 막다른 방 하나가 보물방: 비싼 음식(대형·특수)이 몰려 있고 함정 자리가 전부 차 있음. 스테이지 안내에 "막다른 방 하나는 보물방".
  - 볼 것: 돌아갈 만한 보상인지, 함정이 너무 빽빽하지 않은지.
  - 내 검증: 10맵 평균 보물방 669(보통 방 213의 약 3배, 최소 268), 맵 전체 식량 총량은 그대로, 함정 자리 전부, 안내 토스트 화면, 예외 0.

- [ ] **U-86 FPS 표시·성능** — 개발 빌드 왼쪽 아래 DEV 패널에 `FPS · 평균 ms · 1% ms` 줄(10초마다 갱신). 윈도우 PC에서 벽 속 스테이지 5를 켜고 144fps 근처인지 봐 주세요: `Rat.exe -autohost -unitytransport -autostage 5 -perflog` (로그에 "성능:" 줄).
  - 내 검증: 이 맥 혼자 호스트 1080p 275fps(1% 7.0ms), 레티나 전체 화면 221fps(1% 7.4ms). 에디터와 같이 돌린 46fps는 에디터 몫.

- [ ] **U-87 배관은 울린다** — 회색 배관 안에서 Shift로 뛰면 **양쪽 입구 밖에서** 쿵쿵(35, 소음 파문이 입구에 생김). 걷거나 웅크리면 조용. 입구 근처(약 5m) 고양이가 듣는다.
  - 내 검증: 입구 3.3m 옆 고양이 — 배관 안 달리기 들음 2, 걷기 0. 처음엔 발밑 소리만 키웠는데 관 벽에 막혀 못 들어서 입구에서 나게 바꿈. 예외 0.

## 3. 협동·쥐 시스템 (창고 맵)

- [ ] **U-11 쓰러진 동료 운반·부활** (2인) — F4 "쓰러지기" → **옆으로 누운 쥐**(내 털 색을 칙칙하게)가 생김 → 동료가 좌클릭으로 잡고 끌어 쥐구멍에 넣으면 부활. 혼자면 쓰러진 뒤 F4 "살리기".
- [ ] **U-12 치즈 먹기** — 치즈(작은 것)를 들고 E 1초 길게 → 없어지고 스태미나 +50, 토스트.
- [ ] **U-13 함정 3종** — F4 "함정"으로 가기. 쥐덫: 밟으면 쓰러짐+큰 소리, 물건을 던져도 튕김(1회). 끈끈이: 붙잡힘 → 동료가 E 1.5초로 구출. 전기선: 1.5초마다 켜짐/꺼짐, 켜졌을 때 닿으면 2초 기절.
- [ ] **U-14 소리 파문** — 물건을 떨어뜨리거나 달리면 소리 크기만큼 파문이 퍼짐. 창고방 벽 너머 소리는 고양이가 덜 들음.

## 4. 고양이 — 일상·추격 (창고 맵, F3 켜고 보기)

- [ ] **U-20 스팟 순찰·잠** — 고양이가 잠자리·밥·햇볕 자리를 돌고, 잠자리에선 오래 잠. 얕은 잠(뒤척임)↔깊은 잠, 가끔 한쪽 눈 뜸.
- [ ] **U-21 예측 추격** — 들키면 내가 갈 곳을 앞질러 막음. 지그재그·코너에서 오버슛.
- [ ] **U-22 숨을 곳 수색** — 쫓기다 장화·상자에 숨으면 마지막 본 곳 주변을 킁킁 뒤짐. 상자 입구에 앉아 막기도.
- [ ] **U-23 냄새 자국** — 치즈를 들고 다니면 자국이 남고 고양이가 따라옴.
- [ ] **U-24 장소 기억·앙심** — 같은 자리에서 여러 번 들키면 나중에 그 자리를 확인하러 옴. 도발·놓친 쥐를 찍음.
- [ ] **U-25 귀 돌리기** — 들을락 말락 한 발소리에 귀만 그쪽으로.
- [ ] **U-26 매복** — 커튼 뒤에 꼬리만 내놓고 있다가 덮침.

## 5. 고양이 — 놀이·유인

- [ ] **U-30 호기심 앞발** — 고양이 근처로 물건을 굴리면 쫓아가 툭툭 침. 여러 번 하면 질려서 하품.
- [ ] **U-31 가지고 놀기·물고 옮기기·버둥거리기** — F4 "고양이 내 앞"으로 잡혀 보기 → 툭툭 치고 놓아줌 → 물고 햇볕·침대 자리로 옮김. 잡혔을 때 A·D 번갈아 연타하면 칠 때 그쪽으로 튕김.
- [ ] **U-32 흔들리는 끈** — F4 "흔들리는 끈" → 툭 치면 30초 흔들림 → 보이는 한가한 고양이가 앞발질하러 옴.
- [ ] **U-33 레이저 포인터** — F4 "레이저 포인터"로 가서 집기 → 조준점에 빨간 점 → 한가한 고양이가 쫓음.
- [ ] **U-34 관심 "냥"** — 고양이가 노는 중이면 HUD에 초록 "냥".
- [ ] **U-35 헤어볼** — 그루밍 뒤 가끔 헤어볼(가치 5, 미끄러움)을 뱉음.

## 6. 고양이 — 집주인 이벤트 (F4 버튼으로 바로)

- [ ] **U-40 부르기** — 고양이가 문으로 가서 사라짐 → 잠시 뒤 **다른 문**으로 돌아옴.
- [ ] **U-41 밥 시간** — 고양이가 밥 자리로 서둘러 가서 먹음.
- [ ] **U-42 초인종** — F4 "초인종"으로 가서 E 1초 → 딩동 → 고양이가 따라 나감(런당 1번).
- [ ] **U-43 로봇청소기** — 30초 동안 발소리 묻힘, 물건이 밀림, 고양이는 먼 곳으로 피신.
- [ ] **U-44 TV** — 고양이가 TV 앞에 앉아 90초 화면만 봄 → 등 뒤로 지나갈 수 있음.
- [ ] **U-45 불 켜기** — 어둠 구역에 30초 불 → 고양이가 집주인한테 부비러 감. 어둠 구역 안 쥐는 평소 절반 거리에서만 보임.
- [ ] **U-46 창문 바람** — 20초 동안 냄새 자국이 날아가고 돌풍에 가벼운 물건이 밀림.

## 7. 고양이 — 환경

- [ ] **U-50 선반 관찰대** — 고양이가 선반에 뛰어올라 상자 너머를 내려다봄(선반 밑은 사각).
- [ ] **U-51 문 닫기** — F4 "창고방 문" → 들어가서 E로 닫기 → 쫓던 고양이가 문 앞에서 4초 밀다가 엶.
- [ ] **U-52 후추통** — 던져서 쏟으면 그 자리 냄새가 지워지고, 지나가는 고양이가 재채기.
- [ ] **U-53 물그릇** — 엎으면 웅덩이가 냄새를 지우지만 밟은 쥐는 젖은 발자국을 남김.
