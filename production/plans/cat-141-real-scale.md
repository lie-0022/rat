# 고양이 141 — 쥐·고양이·맵 크기를 실제 비율로 (제안, 2026-09-25, 3번째 루프)

> 사용자 요청(09-25 07:4x): "쥐와 고양이 크기 비율을 실제 비율과 유사하게 — 고양이가 쥐보다 훨씬 크게, 맵도 그 비율로".

## 지금 (잰 값, 게임 단위 = m)

| 무엇 | 지금 | 쥐 대비 |
|---|---|---|

| 고양이 | 키 약 1.9, 길이 2.3(꼬리 포함), 에이전트 반지름 0.55·높이 1.7 | 키 **1.6배** |
| 방 | 6~12 × 6~12, 벽 높이 2.5, 칸 14 | 방 한 변 = 쥐 5~10마리 |
| 문(통로) | 폭 1.8 | 고양이가 딱 지나감 |
| 전리품 | 치즈 조각 0.44, 햄 1.0, 통닭 1.6 | 쥐 키의 1/3 ~ 1.3배 |

## 실제 (참고값)

| 무엇 | 실제 | 쥐(서 있는 생쥐 ≈ 10cm) 대비 |
|---|---|---|
| 고양이 | 머리 높이 25~30cm, 몸 45cm + 꼬리 30cm, 앉으면 40~50cm | 키 **약 3배**, 길이 약 7배 |
| 방문 | 폭 80cm, 높이 2m | 8배 |
| 방 | 3~4m | 30~40배 |
| 천장 | 2.4m | 24배 |
| 치즈 한 조각 | 2~3cm | 1/4 |

## 제안 — 쥐는 그대로 두고(조작감·카메라·점프가 쥐 1.2에 맞춰져 있음) 고양이와 세상을 키운다

1. **고양이**: 키 1.2 × 3 ≈ **3.6**(지금의 약 1.9배). 몸길이 약 6. 에이전트 반지름·높이·보폭(속도)·앞발 닿는 거리·잡는 거리도 같은 배율. NavMesh는 고양이용 에이전트 크기로 다시 굽는다.
2. **맵(벽 속)**: 방·문·벽 높이를 고양이가 드나들 만큼 — 문 폭 1.8 → **약 4**, 벽 높이 2.5 → **약 6**, 방 6~12 → **약 12~24**(칸 14 → 약 28). 쥐 전용 배관은 쥐 크기 그대로(고양이 못 들어감이 더 분명해짐).
3. **한 판 길이**: 방 수 그대로(사용자 결정) — 이동 시간이 늘어난 만큼 한 판이 길어진다.
4. **소리·시야·냄새 반경**: 고양이 감각 반경은 방 크기에 맞춰 키움(아니면 큰 방에서 고양이가 장님이 됨). 쥐가 내는 소리 반경은 그대로 → "큰 고양이 옆에서 살금살금" 느낌.
5. **전리품**: 크기는 그대로(이미 쥐 대비 현실에 가까움).
6. **창고 데모·기지**: 1차는 벽 속만. 창고 맵은 고양이만 커지면 문·가구가 막히므로 나중에(또는 고양이 크기를 씬별로).

## 단계 (각각 커밋·확인)
1. 배율 수치를 데이터로(`BalanceConfigSO` 또는 테마 SO — 하드코딩 금지) + 고양이 프리팹 스케일·에이전트.
2. 벽 속 방 킷을 새 크기로 다시 생성(방 7종·통로·배관 — 프리팹 churn은 의도된 것).
3. 고양이 감각·속도 배율, NavMesh 굽기 확인(문 통과·갇힘 0 — 맵 불변 검사 25판).
4. 통째 소크 + 스크린샷 비교(전/후), 2인.

## 사용자 결정 (2026-09-25 07:5x)
- 고양이 배율: **현실 3배**(쥐 키 1.2 → 고양이 키 약 3.6).
- 한 판 길이: **방 수 그대로**(맵이 넓어진 만큼 한 판이 길어짐 — 할당량 판단 7과 같이 보기).

## 진행
### ① 벽 속 맵 ×2 (2026-09-25)
- `GridZoneSO`에 `RoomScale` 2·`WallHeight` 6·`DoorWidth` 4 — 방 킷 도구(`Create Wall Rooms`)가 읽어 방 7종·통로·배관 입구를 다시 만든다(칸 14 → 28). 전리품·함정 수는 **예전 넓이 기준 그대로**(맵 식량 총량 불변 — 판단 7과 안 엮이게), 숨을 곳·스팟 안쪽 여백·상자·장식(샛기둥·단열재·천장 배관)·안전지대 불빛은 배율대로. 쥐 전용 배관 구멍은 쥐 크기 그대로. 미끼 찾는 거리 6 → 12.
- 확인: 스테이지 1 방 15·통로 14, 맵 130×158m, 출발방에서 NavMesh로 방 13/13 도달, 가장 먼 방 경로 168m. 모습 `cat-141/step1_room_x2_cat_old.png`(고양이는 아직 예전 크기 — ②).
- 창고 데모·기지·부엌(생성) 맵은 그대로(고양이 크기도 거기선 그대로 둘 예정).

### ② 벽 속 고양이 키우기 (2026-09-25)
- `GridZoneSO.CatSizeScale` 1.9 → 벽 속에서 스폰하는 고양이만 스폰 전에 `CatBrain.ServerPrepareSize`: 몸 ×1.9(키 1.9 → **3.6**, 길이 5.0 = 쥐 키 3배), **이 고양이 전용 균형값 복사본**(`BalanceConfigSO.ScaledForCat` — 잡기·앞발·가까운 시야·뇌물·놀이 밀기/도주·추격 오버슛·수색·기억 칸·시야 8→15.2·선반 시야·냄새·물고 옮기기·매복 덮침·싸움·문지기 둘레 ×1.9). **속도는 그대로**(추격 5.5 < 쥐 달리기 7 축). 크기는 NetworkTransform 스케일 동기화로 클라에도.
- 큰 고양이 NavMesh: 도구 `Tools/RatGame/Zone/Create Big Cat Nav Agent` → 프로젝트 NavMesh 설정에 에이전트 타입 **"BigCat"**(반지름 1.1·높이 3.4, 번호는 테마 SO에). 벽 속 NavMeshSurface가 그 타입으로 굽고 고양이 에이전트도 그 타입.
- 창고 데모·부엌(생성)·기지 고양이는 예전 크기 그대로(스케일 1, 기본 에이전트) — 1번째 루프 확인 대상이 안 바뀌게.
- 방울 판정 거리도 고양이 몸 배율만큼(큰 고양이 몸 안쪽에서 판정이 끝나지 않게).
- 바꾼 것 ①: 에이전트 번호가 음수(-1372625422)라 `>= 0` 검사에 걸려 안 붙었음 → "-1만 없음".
- 바꾼 것 ②: NavMeshAgent 반지름·높이도 트랜스폼 배율이 곱해져 회피 반경 1.8(몸 1.1보다 큼) → 고양이 셋이 한 방에서 서로 밀치다 목적지 0.8m 앞에서 **56초** 멈춤 → 에이전트 반지름·높이를 구운 크기에 맞추고 도착 여유 = 반지름의 반. 다시 90초: 움직이려는데 막힌 시간 최대 **2초**, 순찰꾼 방 3개·81m, 오류 0.
- 확인: 스테이지 5 고양이 3마리 모두 BigCat NavMesh 위, 배율 3.23(키 3.59·길이 5.0), 시야 15.2·잡기 1.9. 쥐 눈높이 스크린샷 `cat-141/step2_rat_view_big_cat.png`. 2인: 클라에서도 고양이 배율 3.23(`report`), 오류 0.
- 알려진 것: CatVisual의 몸 늘이기·줄이기 연출이 캡슐 가운데 기준이라 커진 만큼 발밑이 살짝 뜨는 순간이 더 잘 보임(그레이박스 — 모델 들어오면 사라짐).
