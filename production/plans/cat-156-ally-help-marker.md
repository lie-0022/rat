# 고양이 156 — 위기인 동료 위에 표시 (구해질 때까지) (2026-09-26, 3번째 루프)

## 왜
- 155에서 알림 순간 "앞 28m"은 주지만 한 번뿐 — 달려가는 동안 방향이 바뀌면 다시 Tab 지도를 열어야 한다.
- 핑 마커(벽 뒤도 보이는 오버레이)와 같은 모양으로 **위기인 동료 머리 위**에 표시를 계속 두면 구하러 가는 길이 끊기지 않는다(협동 필러). 벽 속 맵이 2배라(141) 더 필요.

## 규칙 (잠정)
- 내가 아닌 쥐가 **다운·끈끈이·잡힘**이면 그 쥐 위(1.2m)에 핑과 같은 마커: 팀색 마름모 + "파랑 쥐 · 다운"(글자 빨강) + 거리. 화면 밖이면 가장자리에 반투명. 상태가 풀리면(부활·구출·풀려남) 사라짐.
- 핑과 따로(쥐마다 핑 하나 + 위기 표시 하나). 0.25초마다 상태를 훑는다(동기화 없음 — 상태·위치는 이미 모두에게 있음).
- 새 밸런스 수치 없음(표시 색은 위젯 직렬화 값).

## 확인 계획
- 2인: 클라 다운 → 호스트 화면에 마커·거리, 부활 → 사라짐. 끈끈이도. 스크린샷(벽 뒤로도 보이는지).
