# 고양이 3 — 성격 프로필 2종 (2026-09-24, 세트 1의 3단계)

## 목표
같은 FSM에 성격 프로필을 얹어 판마다 "이번 놈은 어떤 놈?"이 생기게. 데모는 **게으름뱅이·사냥꾼** 둘 (design/cat-ideas/01).

## 설계
- `Data/CatPersonalitySO`: 이름·몸 색 + 배율(시야·청각·추격 속도·수면 시간·잠자리 가중치·관찰점 가중치·관찰점 머무름) + 추격 포기 초.
- `CatBrain._personalities[]` (프리팹) → 스폰 시 랜덤 → `PersonalityIndex` NV(클라 색). `ServerSetPersonality(i)`로 지정 가능(존 생성기·테스트).
- `CatSenses.ViewMultiplier/HearingMultiplier` — 시야 거리·청각에 곱.
- 게으름뱅이: 시야 0.8 · 청각 0.7 · 추격 1.1 · 수면 1.5 · 잠자리 가중치 2 · 추격 8s 뒤 포기. 몸 색 회갈색.
- 사냥꾼: 시야 1.3 · 청각 0.9 · 수면 0.5 · 관찰점 가중치 1.5 · 관찰점 머무름 3(≈ 6~15s 관찰). 몸 색 진회색. (선반 Perch는 맵 층이 생기면.)
- `CatVisual` 몸 기본색 = 성격 색.

## 검증
- 게으름뱅이: 잠 90s, 추격 8s 뒤 "추격 포기" 로그 → Return. 9m 거리 목격 안 됨(시야 6.4).
- 사냥꾼: 9.5m에서 목격됨(시야 10.4), 잠 30s.
