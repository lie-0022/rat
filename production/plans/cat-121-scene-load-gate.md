# 고양이 121 — 스테이지 로드가 유령 연결에 묶이지 않게 (2026-09-25)

> 근거: 고양이 67부터 남은 후보 "유령 연결 로드 대기 멈춤". 고양이 120 2인 시험에서 실제로 스테이지 다시 열기가 한동안 멈춤.

- `Run/SceneLoadGate`: 클라별 로드 완료 + 끊김 때 다시 확인 → 지금 접속한 전원이 로드했으면 한 번 실행(NGO 이벤트와 먼저 오는 쪽). RunManager 자동 출발·GridZoneBuilder 맵 짓기가 씀(구독 순서 그대로라 실행 순서 같음).
- 확인: 기지 → 벽 속 정상 출발 6.1초. 2인에서 클라 프로세스를 멈추고(SIGSTOP) 스테이지 2 로드 → 28.7초(전송 끊김 30초)에 호스트가 맵 짓기, 접속 1. 전엔 NGO LoadSceneTimeOut 120초까지 멈출 수 있었음.
