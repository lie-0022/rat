# 고양이 181 — 빈손 귀환 경고 (2026-09-28, 3번째 루프)

## 왜 (179 시험 하다 발견)
- 예전 루프 맵(창고·부엌)은 할당량이 없어서, 모두 쥐구멍에 3초 서 있으면 **식량 0이어도 귀환**한다.
- 모이는 줄("쥐구멍에 모이면 귀환 1/2")과 카운트다운("귀환 중… 3")만 떠서, 아무것도 못 챙긴 채 실수로 판이 끝나도 결과 화면에서야 안다.
- 새 루프(벽 속)는 할당량을 못 채우면 아예 못 떠나니 해당 없음.

## 한 것
- 런 바 둘째 줄(예전 루프만): 쥐구멍 적립 0 **이고** 누구 손·주머니에도 값 있는 물건이 없으면
  - 모이는 중: "쥐구멍에 모이면 귀환 1/2 · 아직 빈손이에요" (주의 색)
  - 카운트다운: "귀환 중… 3 · 빈손" (주의 색)
- 들고 있는 물건은 0.5초마다 모든 쥐의 운반 컨트롤러를 훑어 센다(손 + 주머니, 동기화된 값만 읽음 — 클라에서도 맞음).
- 막지는 않는다 — 빈손으로 일부러 나가는 것도 선택. 알려만 준다.
- 새 밸런스 수치 없음.

## 확인 계획
- 창고 2인: 아무것도 안 들고 쥐구멍 → 모이는 줄·카운트다운에 빈손 표시, 호스트·클라 둘 다.
- 물건 하나 들고 쥐구멍 → 빈손 표시 없음. 적립 1회 뒤 → 없음.
- 오류 0.
