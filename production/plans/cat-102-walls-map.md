# 고양이 102 — 벽 속 지도 (Tab) (2026-09-25)

> 근거: 벽 속은 방 13~19개 + 고리 미로. 킁킁(76)은 "다음 문"만 알려 준다. 어디를 가 봤고 어느 출구가 남았는지 보는 지도가 있으면 탐험·우회(갈래·배관·보물방)가 쉬워진다. 사양 docs/12 WallsMap.

## 규칙
- Tab 누르고 있는 동안 화면 가운데 지도. 벽 속(GridRoom이 있는 맵)에서만.
- 안개: 내가 들어가 본 방만 그림(+ 목적지는 항상, 출발방은 처음부터 가 본 것).
- 가 본 방의 열린 면마다 짧은 선 → 안 가 본 출구가 보인다. 배관 면은 회색.
- 점: 나(흰색), 동료(팀색). 목적지 방 주황.
- 로컬 기록(동기화 없음), 스테이지(씬)가 바뀌면 새로.

## 구현
- `UI/WallsMapWidget`(Hud) + `Editor/HudMapTools`(`Tools/RatGame/UI/Build Walls Map`) — 창·방/선/점 템플릿.
- F1 안내 목록에 "Tab 지도(벽 속)".

## 확인 (계획)
- 1인: 출발 → 방 몇 개 이동 후 Tab 스크린샷(가 본 방·출구 선·목적지·내 점). 2인: 동료 점 위치.

## 진행 — 구현·확인 (2026-09-25)
- `UI/WallsMapWidget`(방 사각형은 맵마다 한 번 만들고 가 본 방만 켬, 0.25초마다 내 위치로 방문 기록, 점은 누르고 있는 동안만 갱신), `Editor/HudMapTools`(`Tools/RatGame/UI/Build Walls Map` → Hud `MapArea`), F1 목록 "Tab 지도".
- 확인: 출발에서 가까운 방 4개를 거친 뒤 Tab → 가 본 방 5개(출발 포함) + 각 방 열린 면 짧은 선(안 가 본 출구) + 목적지 주황(오른쪽 멀리) + 내 흰 점(출발방). 동료 점은 클라에도 있는 쥐 오브젝트라 같은 코드 — 다음 소크에서 2인 화면.
