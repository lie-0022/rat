# 고양이 137 — 상대 이동 보간·점프·웅크림 동기화 (docs/04 수용 기준, 2026-09-25)

- 도구: `DevRemoteControl`에 `report`(이 클라에서 보이는 모든 쥐의 위치·키·상태 로그), `trace:초`(이 클라에서 호스트 쥐를 매 프레임 재서 요약 — 이동·프레임 최대·튐(>0.5m)·멈춘 프레임·최고 y).
- 방법: 에디터 호스트(기지) + 빌드 클라. 호스트가 걷기(`DevForcedInput`, 막힘 없는 9.5m 직선)·웅크림(`DevForcedCrouch`)·점프(실제 버퍼 경로) → 클라 로그로 확인.

| 확인 | 클라에서 본 호스트 | 호스트 자신 |
|---|---|---|
| 걷기 2초 | 217프레임, 8.10m, 프레임 최대 0.077m(평균 0.037), 튐 0, 멈춘 프레임 4 | 8.72m, 프레임 최대 0.140m |
| 웅크림 | 키 0.30 → 서면 0.60 | 0.30 / 0.60 |
| 점프 | 최고 y 2.27, 프레임 최대 0.053m | 2.32 |

- 첫 걷기 시험은 호스트가 1초 만에 벽에 막혀 "멈춘 프레임"이 많았음(실제로 서 있던 것) → 빈 직선에서 다시.
- 결론: 매 프레임 조금씩(평균의 2배 안) — 틱마다 뚝뚝 끊기지 않고 보간됨. MPPM 창 자체 확인은 docs/01(사람).
