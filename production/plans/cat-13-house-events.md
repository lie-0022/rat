# 고양이 13 — 집주인 이벤트: 부르기·밥 시간 (2026-09-24, 세트 2의 8단계)

## 목표
고양이 밖에서 오는 사건으로 판의 막을 나눈다. 인간은 안 보인다 — 목소리·소리만. 이번엔 새 오브젝트 없이 되는 두 가지. (design/cat-ideas/10)
- **부르기**: 멀리서 "나비야~ 간식!"(예고 3s) → 고양이가 하던 일을 멈추고(추격도 끊음 — 간식이 더 중요, 놀이·포획 중이면 끝난 뒤) 문으로 나가 **20~40s 사라짐** → **랜덤 문**으로 돌아옴(어느 문일지 도박).
- **밥 시간**: 부엌에서 그릇 달그락(예고 3s) → 고양이가 밥그릇(Food 스팟)으로 가서 25s 먹음(감각 0.5) — 부엌만 위험. 목격 전이는 그대로.

## 설계
- `CatSpotType.Door` 추가(enum 끝) — 데모 레이아웃에 문 2개(서 -19,0,0 / 동 19,0,6). 문이 없으면 가장 먼 스팟으로 퇴장.
- `CatState.Away` + `AI/CatBrain.House.cs`: `ServerCallAway(seconds)` — 가까운 문으로 3.0 속도 → 도착하면 숨김(`CatVisual`이 렌더러 끔)·감각 0 → 시간 끝 → 랜덤 문으로 순간이동(Warp)·보임 → Return. `ServerFeedingTime(seconds)` — Patrol로 돌려 Food 스팟 강제 + 도착 머무름 = 남은 밥 시간.
- `Run/HouseEventDirector` (호스트, RunManager가 런타임 부착 — RunDirector와 같은 방식): 스테이지당 2~4개, 첫 사건 90~150s, 간격 180~300s, 같은 사건 연속 금지. **경계도 디렉터가 Relief면**(몰리는 중) 마지막 사건 뒤 90s가 지났을 때 부르기를 앞당긴다. 테스트·다른 시스템용 `ServerTrigger(kind)`.
- 예고·시작·끝 알림: `RunManager.HouseEventClientRpc(kind, phase)` → 각 클라 `EventBus.HouseEvent` → ToastWidget ("멀리서 '나비야~ 간식!'" / "고양이가 나갔다! 지금이야" / "고양이가 돌아왔다… 어느 문으로?" / "부엌에서 그릇 달그락 — 밥 시간"). 목소리는 NoiseSystem이 아니다(고양이가 반응하면 안 되는 소리).
- 수치 (BalanceConfig "집주인 이벤트"): houseEventsPerStage (2,4) · houseEventFirstDelay (90,150) · houseEventGap (180,300) · houseEventWarnSeconds 3 · catCallAwaySeconds (20,40) · catFeedingSeconds 25 · catAwayWalkSpeed 3 · reliefCallAwayMinGap 90.
- 나중: 청소기(지속 소음 마스킹 + 물리 밀기), 불 켜짐(LightZone), TV, 초인종(쥐가 유발).

## 검증
- 부르기: 추격 중 트리거 → 예고 3s 뒤 추격 끊고 문으로 → 숨김(렌더러 꺼짐)·감각 0 → 20~40s 뒤 다른/같은 문에서 등장 → Return.
- 밥 시간: 트리거 → Food 스팟 도착 → 머무름 ≈ 남은 시간.
- 스케줄러: 첫 사건 시각·간격(시간 단축 테스트), Relief 앞당김.
- 2인: 클라 토스트 로그(EventBus) + 클라에서 고양이 숨김(Away 상태 복제).

## 검증 결과 (2026-09-24)
- 부르기(1인): 예고 3s 동안 고양이가 추격 시작(0.8s) → 3.0s에 추격 끊고 Away → 서쪽 문(-19,0,0)에서 숨김(렌더러 꺼짐) → 4s(테스트) 뒤 랜덤 문(서쪽)으로 등장·렌더러 켜짐 → Return.
- 밥 시간: 문에서 Food(14,14)까지 달려가 도착(13.7s — 테스트 밥 시간 12s라 도착 즈음 끝) → 끝나면 Patrol. 실제 25s·3 m/s면 대부분 먹는 시간.
- 스케줄러: Phase StageActive + 테스트 수치(첫 1s·간격 6s·2건) → 7.0s 안에 2건(부르기 → 밥 시간 번갈아).
- 2인: 빌드 클라 로그에 토스트 3종("나비야~" → "나갔다" → "돌아왔다… 어느 문으로?")과 "고양이 모습: 숨김 → 보임".
- 발견: 짧은 테스트 간격에선 고양이가 밖에 있는 동안 다음 사건(밥 시간)이 시작돼 무시됨 — 실제 간격(180s+)에선 안 겹침. 필요하면 "고양이가 Away면 다음 사건 미룸" 추가.
- 미검증: Relief 앞당김(디렉터 연동, 조건 한 줄), 놀이 중 부르기 → 끝난 뒤 나감.
