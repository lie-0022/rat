# 고양이 82 — 문지기를 알아보게 (2026-09-25)

> 근거: 문지기(고양이 80)가 다른 고양이와 똑같이 생겨서 누가 지키는지 모른다. 새 동기화 없이 — 성격 인덱스는 이미 NV.

## 규칙
- 문지기 = 전용 성격 "문지기"(푸른 회색 #7E9CB8, 눈·귀 조금 밝음, 잠 짧음, 관찰점 선호). 무작위 추첨 제외(아기와 같은 `RoleOnly`).
- 문지기로 정해지면 이 성격으로 바뀐다 → 클라에 색·이름.

## 구현
- `CatPersonalitySO._isGuard`·`IsGuard`·`RoleOnly`, `PickRandomPersonality`가 RoleOnly 제외, `ServerMakeGuard`에서 성격 지정. `Editor/CatGuardTools`(`Tools/RatGame/Cat/Create Guard Personality` — 에셋 + Cat 프리팹 목록 끝에 추가, 인덱스 5).

## 확인
| 확인 | 결과 |
|---|---|
| 호스트 | 스테이지 4: 문지기 배정 → 성격 "문지기" |
| 2인 | 클라 "고양이 성격 연출: 문지기" + 다른 한 마리는 무작위 성격(겁쟁이 — 문지기·아기 안 뽑힘) |
| 화면 | 푸른 회색 고양이(상자 앞 BoxSit) — 다른 성격 색과 구분됨 |
| 예외 | 0 |

- 같이 발견: 2인일 때 팀 상자가 길어지는데 F1 꼬리표(고양이 77)가 고정 위치라 두 번째 줄을 가림 → 다음 작업(고양이 83)에서 고침.
