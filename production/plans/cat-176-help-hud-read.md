# 고양이 176 — F1 안내에 "화면 읽기" (2026-09-28, 3번째 루프)

## 왜
- 3번째 루프에서 화면 표시가 여럿 늘었다(고양이 "?" 밑 이유·"? 냄새"·오른쪽 아래 소리/냄새·위기인 동료 표시·핑한 고양이). 뜻을 알려 주는 곳이 없어 처음엔 뭔지 모른다. F1 조작 안내는 키만 있다.

## 한 것
- F1 목록 아래에 "화면 읽기" 3줄: **고양이 머리 위** — ? 의심(밑에 이유: 봤다·발소리·냄새…), ! 추격 / **오른쪽 아래** — 내 소리 크기·냄새 남기는 중 / **빨간 표시** — 위기인 동료(구해질 때까지).
- 창 높이 520 → 640(도구 값도 같이). 도구를 다시 돌리면 안내 영역 전체가 새로 만들어져 프리팹이 723줄 바뀌어서 → 되돌리고 창 높이 한 줄만 고침.

## 확인 계획
- F1 스크린샷 — 줄이 창 안에 다 들어가는지, 읽을 만한 크기인지.

## 하다가 찾은 버그 — 한글 자판이면 키 이름이 자모
- 스크린샷에서 키가 **"ㅈ/ㅁ/ㄴ/ㅇ 이동", "ㄷ 상호작용", "ㅂ 찍찍", "ㄹ 핑", "ㄱ 킁킁"** — 키 표시 이름이 지금 입력 언어를 따라가서, 맥 입력기가 한글이면 자모로 나옴(전에 찍은 F1 사진은 영문 입력이라 W/A/S/D였음). 한국 사용자는 대부분 한글 입력 상태라 헷갈림.
- 고침: 키 **자리 이름**(`<Keyboard>/w` → "W")으로. 이동은 위·아래·왼·오 순서라 "W/S/A/D"가 되던 것도 "W/A/S/D"로.

## 확인 (2026-09-28)
- 한글 입력 상태에서 자리 이름: w→W, e→E, q→Q, r→R, f→F, leftShift→Shift, leftCtrl→Ctrl, space→Space, 마우스 좌/우/휠클릭, escape→Esc, tab→Tab.
- 목록 전체(프리팹 위젯으로): "W/A/S/D 이동 | Shift 달리기 | … | E 상호작용 | Q 찍찍 | 휠클릭 / F 핑 | R 킁킁 | … | 화면 읽기 | 고양이 위 ? 의심(밑에 이유) · ! 추격 | 오른쪽 아래 — 내 소리 크기 · 냄새 남기는 중 | 빨간 표시 — 위기인 동료".
- 모습 `cat-176/f1_help.png`(이동 순서 고치기 직전 — "W/S/A/D"로 보임, 나머지는 같음): 창 640 안에 다 들어가고 한 줄씩.
- 다른 화면에 키 표시 이름을 쓰는 곳 없음(찾아봄).
