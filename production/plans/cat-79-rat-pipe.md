# 고양이 79 — 쥐 전용 배관 (기획, 2026-09-25)

> 근거: 맵 시안 "벽 속" + 필러(은신). 지금 배관(IsPipe, 고리를 닫는 연결)은 색만 다른 통로라 고양이도 그대로 지나간다.

## 규칙
- 배관 = 폭 1.2m·높이 1.4m 관. 쥐는 서서 통과(키 1.2m), 고양이는 NavMesh가 안 이어져 못 들어감(필요 높이 2m).
- 방 쪽 입구: 막음벽 대신 입구 판(아래 가운데 1.2×1.4 구멍) — 문틈 1.8×2.5를 배관 크기로 좁힌다.
- 배관은 고리를 닫는 연결에만 있어서, 고양이는 문 통로(나무)만으로 모든 방에 간다.
- 결과: 쫓기면 배관으로 빠져 고리를 돌아 떼어 낼 수 있다(고양이는 돌아가야 함).

## 구현
1. `GridPlan.PipeSides(cell)` + `GridZoneLayout.Result.Sides`에 위 4비트로 합침.
2. `GridRoom`: `_pipeMouths[4]` — 면이 열려 있고 배관이면 입구 판 켜기, 막혔으면 막음벽, 문이면 둘 다 끔. `OpenSides` 위 4비트 사용(새 NV 없음, docs/03 표에 GridRoom 행 추가).
3. 에디터 `Create Wall Rooms`: 방마다 입구 판 4개(구멍 둘레 3조각, NoiseBlocker), `Wall_Pipe` 프리팹 = 좁은 바닥·낮은 벽·천장 판. 미리보기도 같은 비트.
4. 확인: 시드 몇 개 — 배관 있는 맵에서 NavMesh로 배관 양 끝 사이 경로가 배관을 안 지나는지(경로 길이 > 배관 길이), 쥐가 배관을 걸어서 통과(DevForcedInput), 모든 방 고양이 도달 가능(미리보기 검사), 2인 클라에 입구 판 모양 같음.

## 진행 — 구현·확인 (2026-09-25)
- `GridPlan.PipeSides`, `GridZoneLayout` Sides 위 4비트, `GridRoom._pipeMouths`, `Editor/GridZoneTools.Pipe.cs`(입구 판·배관 프리팹 — Rooms.cs가 300줄을 넘어 나눔), `Create Wall Rooms` 다시 실행(방 7종·통로·배관 덮어씀, GUID 유지). 클라 `배관 입구 연출` 로그(2인 검증용).
- 시드 2000개: 고리 1854 = 배관 1854 (고리마다 배관 정확히 1개).
