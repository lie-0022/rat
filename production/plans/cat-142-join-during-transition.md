# 고양이 142 — 맵 이동 중 참가 막기 (2026-09-25, 3번째 루프)

## 발견
- 고양이 141 배회 소크를 준비하다 두 번째 클라가 "Deferred OnSpawn … NetworkObject was not received within the timeout period 10 second(s)"를 여러 번 찍고 접속에 실패(재시도 5번 모두).
- 설계(docs/03)는 "게임 진행 중 참가는 거부, 로비에서만 합류". 승인 코드도 `GameState.InRun`이면 거부한다.
- 그런데 **다음 맵을 불러오는 동안**(발판 출발 직후·스테이지 사이 결과 화면 뒤, 약 8~10초)은 상태가 `Lobby`로 돌아가 있어서 승인이 나고, 들어오자마자 맵 불러오기와 겹쳐 물체 동기화가 밀려 실패. 친구가 그 순간 Steam 초대를 수락해도 같은 일이 생긴다.

## 고침
- `NetworkLauncher.ApproveConnection`: `RunSession.DepartPending`(맵 이동 중 — 발판·스테이지 사이·개발 다시 불러오기가 켜고, 새 맵에서 출발하는 순간 꺼짐)이면 거부, 이유 "다음 맵으로 이동 중 — 기지로 돌아오면 참가할 수 있어요".

## 확인
| 확인 | 결과 |
|---|---|
| 기지(대조) | 클라 접속 성공 |
| 기지에서 호스트 "이동 중" 켬 | 클라 5번 시도 모두 거부, 클라 로그 "끊긴 이유: 다음 맵으로 이동 중 — 기지로 돌아오면 참가할 수 있어요" ×5, 동기화 시간 초과 0 |
| 끈 뒤 | 클라 접속 성공, 끊긴 이유 0 |
| 실제 발판 출발 | 기지 → 벽 속 이동 틈은 0.6초(3.5s 이동 시작 → 4.1s InRun) — 이어서 온 클라는 InRun 규칙으로 거부, 호스트·기존 클라 출발은 그대로 |

- 메뉴에서 참가하면 이 사유가 그대로 화면에 뜬다(`MainMenuController`가 `DisconnectReason` 표시).
- 곁 발견: 스테이지 사이(결과 → 다음 맵) 이동 틈은 로드 시간만큼(약 8~10초) 길다 — 이번 고침이 주로 막는 곳.
