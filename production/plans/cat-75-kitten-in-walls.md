# 고양이 75 — 벽 속 깊은 곳의 아기 고양이 (2026-09-25)

> 근거: 팀 대화 "고양이 여러 마리, 각자 다른 기믹". 아기 고양이 성격(엄마·아기 관계)은 이미 있었는데, 무작위 성격에서 빠져 있고 "존 생성기가 명시"라고만 돼 있어 생성 맵에선 한 번도 안 나왔다.

## 규칙 (잠정)
- 고양이 2마리 이상인 스테이지에서 `GridZoneSO.KittenChanceByStage` {0, 0, 0.5, 0.5, 0.6} 확률로 한 마리를 아기로. 배열 끝을 넘으면 마지막 값.
- 아기로 바꾸는 건 호스트(`CatBrain.ServerMakeKitten` — 성격 목록에서 IsKitten을 찾아 ServerSetPersonality). 몸 크기·울음 연출은 기존 성격 NV로 클라에 간다(새 동기화 없음).
- 관계(MotherKitten)는 기존 CatRelation이 아기를 보고 붙인다.

## 확인
| 확인 | 결과 |
|---|---|
| 스테이지 5 로드 | "벽 속: 스테이지 5 — Cat(Clone)를 아기로", "고양이 관계: MotherKitten", 연출 "아기 고양이 몸 0.6" |
| 엄마 달려오기 | 아기를 의심 상태로 → 어른 2마리 모두 Respond |
| 예외 | 0 |

넷코드 변경 없음(기존 성격 NV 경로) — 2인 확인은 성격·엄마아기 동기화 검증(plan cat-03·cat-23)으로 갈음. 에셋에는 아직 값이 저장 안 됨 — 필드 기본값이 쓰인다(에셋을 다시 저장하면 들어감).
