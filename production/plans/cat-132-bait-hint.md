# 고양이 132 — 쥐덫 미끼 규칙 안내 (2026-09-25)

## 왜
- 규칙("웅크리고 집기")을 **처음 실패한 뒤에야**(탁 토스트) 알게 된다. 미리 한 번 알려 주면 좋다.

## 처음 한 것 → 바꿈
- 스테이지 안내 토스트에 넣으려 했으나(flags 32) 토스트 칸이 **3개**라 스테이지 1은 이미 꽉 참(스테이지·할당량 / 보물방 / 조작 팁) → 네 번째를 넣으면 맨 앞 할당량 줄이 밀려 사라짐. 되돌림.

## 한 것
- **미끼 얹힌 쥐덫에 처음 3m 안으로 다가가면 한 번**(세션당) "쥐덫 위 음식은 미끼 — 웅크리고(Ctrl) 집기".
- 미끼 여부는 호스트만 알지만 "판 위에 음식"은 모두에게 보이는 위치라 **각자 계산 — 동기화 없음**. 가까울 때만 물건을 훑어 싸다.
- 수치 `BalanceConfigSO.trapBaitHintMeters` 3.

## 확인
| 확인 | 결과 |
|---|---|
| 1인 | F4 "쥐덫 미끼"로 1.6m 앞 → 토스트 "쥐덫 위 음식은 미끼 — 웅크리고(Ctrl) 집기", 로그 한 번 |
| 2인 | 클라를 미끼 쥐덫 1.8m 앞으로(tp) → 클라 로그 "쥐덫 미끼 안내 연출", 30m 떨어진 호스트엔 안 뜸(각자), 클라 오류 0 |
