# 고양이 174 — 냄새를 남기는 중이면 표시 (2026-09-28, 3번째 루프)

## 왜
- 173에서 "내 냄새를 따라오는 고양이"는 보이게 됐다. 그런데 **지금 내가 냄새를 남기고 있는지**는 발밑 노란 점(뒤에 남아서 잘 안 봄)뿐이다. 치즈를 주머니에 넣어도 냄새가 난다는 건 모르고 지나가기 쉽다.

## 규칙
- 소리 표시(170) 바로 위에 작은 줄 **"냄새 · 치즈"**(강도 60) / **"냄새 · 젖은 발"**(40) / **"냄새 · 찍힘"**(20, 고양이 앙심) — 마지막 자국 뒤 2초 동안. 웅크리면 자국 간격 2배라 덜 깜빡임(규칙 그대로).
- 흐름: 호스트가 이미 소유 클라에만 보내는 자국 알림(`ScentMarkClientRpc`) → `EventBus.ScentLeft(강도)`(로컬) → `NoiseMeterWidget`. 새 동기화·새 밸런스 수치 없음(강도 = 기존 값으로 구분).
- 도구 `Build Noise Meter`가 두 번째 줄도 만든다(다시 실행).

## 확인 계획
- 1인: 치즈를 들고 걷기 → "냄새 · 치즈", 내려놓으면 2초 뒤 사라짐. 스크린샷.
