# 고양이 86 — 성능 측정 도구 + 첫 측정 (2026-09-25)

> 근거: docs/13 3-3 "그레이박스 144fps". 새 루프 스테이지 5(방 ~19, 네트 오브젝트 ~180, 고양이 3)가 무거워졌는데 잰 적이 없다.

## 구현
- `Net/DevPerfProbe` (개발 빌드만, 스스로 생김): 10초 창 평균·1% 최악·최대. `-perflog`면 수직 동기화 끄고 로그 "성능: …".
- `Net/DevNetHud`: FPS 줄.
- `Net/DevAutoConnect`: `-autostage N` — `-autohost`와 함께 기지 대신 벽 속 스테이지 N(성능·재현용).

## 결과
- docs/13 "성능 측정" 표: 혼자 호스트 1080p 3.6ms(275fps)·1% 7.0ms, 전체 화면 레티나 4.5ms·1% 7.4ms. 에디터와 같이 돌리면 46fps지만 기지와 같아서 에디터 몫.
- 교훈: 에디터 호스트 + 빌드 클라 조합은 성능 측정에 못 씀 — 빌드 혼자(-autohost -autostage).
