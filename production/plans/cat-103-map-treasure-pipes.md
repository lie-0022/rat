# 고양이 103 — 지도: 보물방 금색·배관 선 파랑 (2026-09-25)

- 가 본 보물방은 금색(클라에도 있는 보물방 불빛 `TreasureGlint` 위치로 방을 찾음).
- 첫 화면에서 문 선(반투명 베이지)과 배관 선(회색)이 어두운 바탕에서 거의 같아 보임 → 문 선은 방 색 불투명, 배관 선은 파랑. 범례 "파란 선 = 배관".
- 확인: 보물방에 서서 Tab → 금색 방 + 내 점, 목적지 주황. 배관이 있는 두 방을 거친 뒤 Tab → 두 방 사이 파란 선, 나머지 문 선 베이지.
- 도구 다시 실행(`Build Walls Map`) — 색은 위젯 직렬화 기본값이라 새로 붙여야 반영.
