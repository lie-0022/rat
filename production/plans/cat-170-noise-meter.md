# 고양이 170 — 내 발소리 크기 표시 (2026-09-28, 3번째 루프)

## 왜
- 은신의 핵심은 소리인데(docs/06), 내가 지금 얼마나 시끄러운지는 파문(40 이상)으로만 보인다 — 걷기 8·달리기 22는 파문이 안 떠서 **"달리면 3m 안 고양이가 듣는다"를 몸으로 배울 방법이 없다**. 웅크리면 0이라는 것도 안내뿐.
- 넓어진 벽 속(141)에선 달려야 할 일이 많아 더 중요.

## 규칙
- 화면 오른쪽 아래 작은 상자: **"소리 · 조용"**(웅크림·멈춤·공중) / **"소리 · 발소리 1m"**(걷기 8) / **"소리 · 쿵쿵 3m"**(달리기 22) / **"소리 · 울림 5m"**(배관 속 달리기 — 양쪽 입구에서, 고양이 87). 거리 = 소음 크기 ÷ 100 × 최대 반경 14m(docs/06 식 그대로).
- 판단은 호스트 발소리 코드(`PlayerNoiseEmitter`)와 같은 기준(수평 속도 1 이상·걷기/달리기 가운데 속도·웅크림 = 몸 높이 75% 미만·발밑 땅·머리 위 배관)을 **내 클라에서 같은 수치로** 다시 계산 — 동기화 없음, 표시만.
- 색: 조용 흐리게, 발소리 보통 글자, 쿵쿵·울림 경고색. 새 밸런스 수치 없음.
- 도구 `Tools/RatGame/UI/Build Noise Meter`(Hud 프리팹에 NoiseArea).

## 확인 계획
- 1인: 멈춤·걷기·달리기·웅크림(원격 강제 입력) → 표시 바뀜 로그 + 스크린샷. 배관 속 달리기 → 울림 5m.

## 확인 (2026-09-28, 1인, 스테이지 1 — 표시만)
- 강제 입력으로: 멈춤 "조용" → 걷기 "발소리 1m" → 달리기(왼쪽 Shift) "쿵쿵 3m" → 웅크려 걷기 "조용"(웅크림이 다 들어가기 전 잠깐 "발소리 1m" — 호스트 발소리 판단도 같은 순간엔 소리를 냄) → 멈춤.
- 배관(8.8m) 입구 3m 앞에서 달려 들어감 — 0.2초 간격: 밖 조용 → 발소리 → **쿵쿵 3m** → 관 안 **울림 5m**(0.8~1.6초) → 나와서 쿵쿵 3m.
- 모습 `cat-170/run_3m.png` — 오른쪽 아래 "소리 · 쿵쿵 3m"(경고색), 슬롯·디버그 창과 안 겹침.
