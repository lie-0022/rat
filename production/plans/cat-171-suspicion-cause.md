# 고양이 171 — 의심 "?" 밑에 이유 (2026-09-28, 3번째 루프)

## 왜
- 고양이가 의심하면 머리 위 "?"와 게이지만 뜬다. **무엇 때문에** 들켰는지(봤나·발소리·물건 떨어뜨린 소리·찍찍)가 없어서, 어떤 행동을 고쳐야 할지 배우기 어렵다. 170(내 발소리 크기)와 짝 — "뛰었더니 '? 발소리'가 떴다".

## 규칙
- "?"(의심) 밑에 작은 글자: **봤다 / 발소리 / 물건 소리 / 찍찍 / 쨍그랑**(깨짐·덫). 게이지를 마지막으로 올린 자극의 종류. "!"(추격)·"냥"(놀이)엔 안 붙임.
- 동기화: 고양이 감각에 `LastCause`(byte) 네트워크 변수 하나 — 호스트만 씀, 값이 바뀔 때만(docs/03 표에 추가). 새 밸런스 수치 없음.

## 확인 계획
- 2인: 클라 쥐가 고양이 뒤에서 달리기 → 클라 화면 "? 발소리", 고양이 앞에 서기 → "? 봤다", 찍찍 → "? 찍찍". 스크린샷 1장.
