# 고양이 180 — 고양이 눈높이를 수치로 + F4로 바꿔 보기 (판단 12 준비, 2026-09-28, 3번째 루프)

## 왜
- 169에서 찾은 "고양이 시야 선이 바닥 위 0.5m에서 나감"은 코드에 박힌 숫자(`Vector3.up * 0.5f`, 세 군데) — **규칙 2(밸런스 수치 하드코딩 금지) 위반**.
- 판단 12(큰 고양이 눈높이)를 사용자가 직접 비교해 보려면 켜고 끄는 방법이 있어야 한다.

## 한 것
- `BalanceConfigSO.catEyeHeight` 0.5(지금 값) + `catEyeHeightScalesWithBody` 끔(지금 그대로). 켜면 눈높이 = 몸 충돌체 윗면 × 0.8(보통 고양이 약 1.4m, 벽 속 큰 고양이 약 2.6m).
- 고양이 감각(쥐 목격·굴러가는 물건 호기심)과 고양이끼리 싸움 시야가 같은 눈높이를 씀.
- F4 확인 메뉴에 "고양이 눈높이: 고정 0.5m / 몸에 맞춤" 버튼(호스트, 개발용 — 에셋은 안 바뀜).
- **기본 동작은 바뀌지 않음** — 판단 12 답이 오면 수치만 바꾸면 된다.

## 확인 계획
- 기본값에서 이전과 같은 결과(눈높이 0.5).
- 벽 속 큰 고양이 앞 상자 뒤 쥐 자리: 고정 0.5m면 가려짐, 몸에 맞춤이면 보임 — 광선으로 숫자 비교.

## 확인 (2026-09-28)
- 눈높이 값: 기본 0.5m(예전과 같음). "몸에 맞춤"이면 벽 속 큰 고양이 **2.6m**, 창고 고양이 **1.4m**.
- **실제로 가려지는 자리 비교** (쥐 가운데 높이 0.6m, 고양이 감각과 같은 가림 층):

| 맵 | 잰 곳 | 가려짐 (0.5m → 몸에 맞춤) |
|---|---|---|
| 벽 속 스테이지 5, 고양이 4마리 앞 15m·±60° | 212곳 | **24 → 24** |
| 창고, 고양이 둘레 8m | 249곳 | **34 → 34** |
- **지금 맵에선 차이 없음** — 시야를 가리는 건 전부 키 큰 벽이고, 쥐가 숨을 만한 낮은 물건은 시야 가림 층이 아니거나(숨을 곳은 따로 "숨음" 상태) 쥐보다 낮다. → 판단 12는 사실상 영향 없음, **그대로 추천**(나중에 낮은 가림 가구가 생기면 이 스위치로 다시 비교).
- 컴파일 오류 0, 기본값 그대로라 게임 동작 바뀐 것 없음.
