# 고양이 77 — 조작 안내 F1 (2026-09-25)

> 근거: 킁킁(R, 고양이 76)처럼 키가 늘었는데 게임 안에 키 안내가 없다. 사용자가 체크리스트를 직접 볼 때도 필요(F3·F4 개발 키 포함).

## 규칙
- 평소: 좌상단 팀 상자 아래 작은 "F1 조작" 꼬리표. F1 → 키 목록 창(다시 F1로 닫기). 조작을 막지 않는다(입력 포커스 안 잡음).
- 키 이름은 입력 에셋 바인딩에서 — 키를 바꾸면 안내도 따라감. 키보드·마우스만(패드는 나중에 따로), 합성은 "W/A/S/D", 마우스는 좌클릭·우클릭·휠클릭(프롬프트 문구와 같게), Left Shift → Shift.
- 메뉴 패널이 열리면 둘 다 숨김. 개발 빌드만 "F3 고양이 정보 · F4 확인 메뉴".

## 구현
- `UI/ControlsHelpWidget`, `Editor/HudHelpTools` (`Tools/RatGame/UI/Build Controls Help` → Hud `HelpArea`: Tag·Panel(Title·List), 테마 색). 에디터 asmdef에 Unity.InputSystem 참조 추가.

## 확인
| 확인 | 결과 |
|---|---|
| 꼬리표 | 팀 상자 바로 아래 "F1 조작" |
| F1 (가짜 키 입력) | 창 열림, 목록 12줄 + 개발 줄: W/A/S/D 이동 … R 킁킁, 키는 제목 강조색(#FFE680) |
| 메뉴 열림 | 꼬리표·창 둘 다 숨김 → 닫으면 창 다시 |
| 예외 | 0 |

UI 로컬 표시만 — 넷코드 변경 없음.
