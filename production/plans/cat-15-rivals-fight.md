# 고양이 15 — 두 마리: 앙숙 싸움 (2026-09-24, design/cat-ideas/07 — 관계 3종 중 앙숙부터)

## 목표
고양이가 두 마리일 때 "1마리 ×2"가 아니라 **관계**. 가장 직관적인 틈인 앙숙부터: 순찰이 겹쳐 마주치면 하악질 → 15s 몸싸움. 그 동안 둘은 서로에게 꽂혀 소리를 못 듣고 거의 못 본다 → 팀이 그 타이밍에 복도를 뚫는다. 쥐가 유인으로 **둘을 한 방으로 모아** 싸움을 일으키는 능동 플레이.

## 설계
- `AI/CatRelation` (호스트 MonoBehaviour, RunManager가 런타임 부착 — 디렉터들과 같은 방식): 고양이가 2마리 이상일 때만 동작. 지금은 관계 = 앙숙 고정(엄마·아기·짝꿍은 다음).
  - 0.25s마다 모든 쌍: 둘 다 "싸울 수 있는" 상태(Patrol·Return·Suspicious·Curious·Track·Search), 4m 안, 서로 가림 없음 → 70% 싸움 / 30% 서로 무시(10s 재판정 금지). 싸움 뒤 30s 재발 금지.
- `CatState.Fight` (`AI/CatBrain.Fight.cs`): 둘이 가운데 지점 주변 1.2m를 1s마다 빙글빙글(속도 3), 상대를 마주 봄. 감각: 청각 차단(소리 무시 — 싸움 소리에 묻힘), 시야 ×0.2. 단 **2m 안 쥐 목격**은 싸움을 깨고 추격(코앞은 못 참음). 15s 뒤 Return.
- CatVisual: Fight = 주황-빨강 번쩍 + 몸 떨림(좌우 빠른 기울기).
- 수치 (BalanceConfig "두 마리"): catFightDistance 4 · catFightChance 0.7 · catFightSeconds 15 · catFightCooldown 30 · catFightDeclineCooldown 10 · catFightViewMul 0.2.
- 데모 스테이지는 1마리 유지(docs/00 — 2마리는 Zone3+). 테스트는 런타임에 두 번째 고양이 스폰.

## 검증
- 두 번째 고양이 스폰 → 둘을 3m 거리 마주 보게 → Fight(확률 → 테스트는 1) → 15s → 둘 다 Return, 쿨다운 동안 재발 안 함.
- 싸움 중 옆에서 소음 90 → 게이지 변화 없음. 쥐가 4m 앞 → 추격 안 함, 1.5m → 추격.
- 2인: 클라에서 두 고양이 Fight 상태 복제(연출 로그).

## 검증 결과 (2026-09-24)
- 런타임 2번째 고양이(Cat2) 스폰, 둘 다 사냥꾼, 3.5m 마주 보며 걷게 → 1.1s 만에 앙숙 싸움(둘 다 Fight).
- 싸움 중 2m 옆 소음 90(Break) → 게이지 0 → 0, Deaf true.
- 쥐가 4m 앞 → 계속 Fight(시야 ×0.2). 1.5m → 0.2s 만에 Chase, 상대는 "싸움 끝" → Return.
- 5s 뒤 다시 붙여도 싸움 없음(쿨다운), 누적 싸움 1회.
- 2인: 빌드 클라 로그 "고양이 싸움 연출: Cat", "Cat(Clone)"(런타임 스폰 고양이 복제 포함).
- 테스트 교훈: ResetPath 뒤 순찰 Arrived → 잠자리 도착 판정으로 잠들어 버림 → 배치할 때 목적지를 준다.
- 미검증: 15s 자연 종료(이번엔 추격으로 끝남 — 타이머 한 줄), 70% 확률(테스트는 1).
