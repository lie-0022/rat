# 고양이 34 — 가지고 놀기 2단계: 물고 옮기기 (2026-09-24, design/cat-ideas/04 Carry, 11 "물고 가다 떨어뜨림")

## 목표
잡은 쥐를 **자기 자리(침대·햇볕)로 물고 간다**. 동료는 고양이가 향하는 곳을 보고 달리고, 원래 자리는 비어서 털 기회가 된다. 가끔 **물고 가다 떨어뜨린다** — 공짜 도주 창(웃김).

## 설계
- ToyPhase.Carry: 놀이 한 판에 한 번, 첫 Bat이 끝났을 때 `catToyCarryChance` 0.6 확률로. 목적지 = Bed·Sun 스팟 중 고양이에서 4~12m(`catToyCarryMinDistance`/`MaxDistance`), 가장 가까운 것. 없으면 안 옮긴다.
- 옮기는 동안 쥐는 Pinned 그대로, 호스트가 0.1s마다 입 위치(고양이 앞 0.6m)로 `TeleportClientRpc` (docs/03 예외 — Nudge와 같은 방식). 속도 순찰 ×1.2(`catToyCarrySpeedMul`), 최대 6s(`catToyCarrySeconds`).
- 도착(또는 시간 끝) → 앞에 내려놓고 Bat 이어서 — 이제 고양이 자리에서.
- 떨어뜨림: 옮기는 동안 초당 `catToyCarryDropChance` 0.1 → 그 자리에 떨구고 바로 Release 창(쥐 Active, 3s 안에 2m 벗어나면 도주 판정 — 기존 규칙).
- 미끼 규칙 그대로: 옮기는 중에도 다른 쥐가 보이면 내려놓고 추격.
- 연출: CatVisual은 Toy 색 그대로, dev 로그 "물고 감 연출"은 서버 로그로 충분(상태 NV 없음 — 클라는 쥐 위치 이동으로 본다).

## 검증 (2인 — 에디터 호스트가 잡히는 쥐, 빌드 클라가 동료)
- 옮기기 확률 1·떨어뜨림 0: 잡힘 → Bat → Carry → 목적지 도착 거리, 호스트 쥐가 고양이 앞 0.6m를 따라감(최대 간격), 도착 뒤 Bat.
- 떨어뜨림 확률 1: Carry 시작 직후 떨어뜨림 → Release → 2m 도주 → Chase.
- 클라에서 호스트 쥐 위치가 따라 움직임(NetworkTransform) — 클라 로그/예외 0.

## 검증 결과 (2026-09-24, 에디터 호스트 + macOS 빌드 클라)
- 옮기기 확률 1·떨어뜨림 0, 호스트가 잡힘: Toy 0.9s → Carry 2.0s(첫 Bat 뒤) → Spot_Sun까지 2.2s·4.7m → 도착 0.8m에서 내려놓고 Bat. 입과 쥐 간격 최대 0.24m.
- 같은 조건, **클라 쥐가 잡힘**(원격 소유 — RPC 10Hz): 2.3s·4.9m 옮김, 간격 최대 0.25 / 평균 0.15m, 도착 뒤 Bat. 클라 예외 0.
- 떨어뜨림 확률 1: 옮긴 지 1.0s에 떨어뜨림 → 호스트 Active(Release) → 2.6m 도주 → 즉시 Chase.
- 미검증: 실제 60%·10% 분포, 옮겨지는 쥐 화면(1인칭 카메라가 10Hz 순간이동으로 덜컹거림 — 웃기면 사양, 어지러우면 보간 검토).
