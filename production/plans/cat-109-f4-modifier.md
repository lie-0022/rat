# 고양이 109 — F4로 오늘의 집 바꾸기 (2026-09-25)

- U-106을 확인하려면 스테이지 확률을 기다려야 해서, F4 메뉴(벽 속)에 "오늘의 집" 줄: 지금 조건 표시 + 없음·정전·덫·간식·외출·분주 버튼 → 그 조건으로 **같은 스테이지를 다시 연다**(기지 출발과 같은 길).
- `GridZoneBuilder.DevForceModifier`는 한 번만 쓰이게 바꿈(다음 맵부터 원래 확률).
- 확인: 스테이지 3에서 "덫" → 다시 열린 맵 TrapSale, 강제 값 비워짐 → 그다음 맵은 굴려서 OwnerOut.
