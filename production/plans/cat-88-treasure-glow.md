# 고양이 88 — 보물방 불빛 (2026-09-25)

> 근거: 보물방(고양이 84)이 있다고 안내만 하고 어디인지 단서가 없다. 막다른 방을 다 뒤지게 하지 말고 "저 문 너머 뭔가 반짝인다"를 주자.

## 구현
- `Treasure_Glow` 프리팹(`Tools/RatGame/Zone/Create Treasure Glow`): NetworkObject + 점광(치즈 노랑, 세기 6, 범위 9, 그림자 없음) + 금빛 부스러기 5개(콜라이더 없음) + `World/TreasureGlint`(세기 ±2 일렁임). NGO 목록 자동 등록.
- `GridZoneBuilder`: 채우기 뒤 보물방 가운데 스폰.

## 확인
| 확인 | 결과 |
|---|---|
| 처음(세기 2.5·주황 금빛) | 옆 방에서 거의 안 보임 — 방 위가 뚫려 있어 낮 햇빛에 묻힘 |
| 세기 6·범위 9 | 통로 끝 보물방 벽이 노랗게, 문틈 양옆에 금빛 번짐, 바닥 부스러기 보임 |
| 목적지와 구분 | 목적지 불빛은 복숭아빛·고정 → 보물방은 치즈 노랑 + 일렁임(3초 샘플 4.0~7.8) |
| 2인 | 클라 "보물방 불빛 연출: (42,0,56)" = 호스트 보물방 위치, 예외 0 |

- 정리: 처음 색으로 만든 머티리얼(Greybox_FFC759)은 안 쓰여서 지움(MCP가 DeleteAsset을 막아 파일로 지움 — 커밋 전, 내가 만든 것).
