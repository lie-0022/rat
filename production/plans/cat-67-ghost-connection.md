# 고양이 67 — 유령 연결 정리 (2026-09-24, docs/03)

## 문제 (고양이 62에서 발견)
호스트가 뜨는 중에 클라가 붙으면 client 1이 "이탈" 로그 뒤에도 연결 목록에 **플레이어 없이** 남았다. 스테이지 씬 로드가 전원 완료를 기다려 출발·맵 생성이 멈춤(NGO 기본 시간 제한까지).

## 해결
- `NetPlayerSpawner.Update`(호스트, 1초마다): 게임플레이 씬에서 호스트가 아닌 연결 중 플레이어 없는 상태가 `_ghostSeconds`(20s) 넘으면 `DisconnectClient` + 로그. 정상 합류는 씬 동기화 뒤 1~3초 안에 플레이어가 생기고, 플레이어는 씬을 넘어 유지돼 전환 중엔 해당 없음.

## 확인
| 항목 | 결과 |
|---|---|
| 인위적 유령(호스트에서 클라 플레이어 Despawn) | 20s에 "유령 연결 정리: client 1 … 끊음", "클라 이탈" |
| 클라 쪽 | Lobby → MainMenu 정상 복귀 |
| 정리 뒤 출발 | 벽 속 StageActive 4.1s |
- 실제 유령(승인 중 끊김) 재현은 타이밍이 필요해 인위적 유령으로 확인함.
