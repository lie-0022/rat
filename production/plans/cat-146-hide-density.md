# 고양이 146 — 넓어진 방에 숨을 곳 늘리기 (2026-09-26, 3번째 루프)

## 왜
- 고양이 141로 벽 속 방 넓이가 4배가 됐는데 숨을 곳은 방마다 1~2개 그대로(모서리 두 곳). 쫓길 때 가까이 숨을 데가 없다.
- 숨을 곳은 식량이 아니라 할당량(판단 7)과 안 엮인다 — 전리품·함정 수와 달리 넓이에 맞춰 늘려도 된다.

## 한 것
- 방 킷 도구(`Create Wall Rooms`): 숨을 곳 수 = 예전 수 × `RoomScale`(최대 4) — 작은 방 1 → 2, 큰 방 2 → 4. 자리: 대각선 두 모서리 먼저, 그다음 나머지 두 모서리(방 가운데를 봄). 방 킷 다시 생성(+ 배관 물).

## 확인
| 확인 | 결과 |
|---|---|
| 프리팹 | 숨을 곳 표시 작은 방 2·중간 2·넓은 2·긴 2·큰 방 4 (전엔 1·1·1·1·2), 전리품 자리 4·6·8·8·14 그대로 |
| 맵 | 스테이지 1 숨을 곳 34개·스테이지 5 32개(전엔 15~20), 전리품 83개 그대로 |
| 겹침 | 숨을 곳 32개 모두 벽과 안 겹침 |
| 숨기 | 새 모서리 상자에 들어가기 → Hidden → 나오기 → Active |
