# 고양이 61 — 반지 스폰 규칙 (2026-09-24, docs/10) — ✅ 완료

## 구현 (커밋됨, 검증 절반)
- `ZoneBuilder.SpawnRing`: 반지(loot_ring)는 무작위 전리품 롤에서 빠지고, 존의 고양이 침대(Bed 스팟) 하나를 골라 **0.8~1.8m 옆 NavMesh 위**에 1개 고정 스폰. 침대가 없는 존(체인이 짧게 끊긴 경우)은 고양이 시작 자리 옆. `RingPos`/`RingAnchor` 테스트용.
- 침대 보장: 직선방 스팟에 Bed 추가(Look·Food·Bed). 중간방은 4종 중 3~4개를 중복 없이 뽑으므로 직선방·홀 중 하나는 항상 들어감 → 존마다 침대 ≥1.
