# 고양이 186 — 결과 화면에 구조 횟수 (2026-09-28, 3번째 루프)

## 왜 (181~185 협동 흐름 끝에)
- 결과 화면 "오늘의 쥐들"은 쥐구멍 적립·들고 온 것·일꾼 왕관·쓰러짐만 보여 준다. **동료를 구한 쥐**는 아무 표시가 없다 — 끈끈이에서 떼어 주기(E 길게), 쓰러진 몸 끌고 오기는 판을 살리는 일인데 식량을 못 모은 쥐로만 보인다.
- 협동 게임에서 "내가 너 살렸다"가 결과에 남으면 웃기고 뿌듯하다(필러: 협동·웃음).

## 할 것
1. `EventBus.RatRescued(rescuer, rescued)` — 호스트에서만 발생:
   - 끈끈이 구출(`PlayerCondition.ServerInteract`) — 떼어 준 쥐 1명.
   - 쓰러진 몸 부활(`DepositZone` 몸 분기) — 그 순간 몸을 들고 있던 쥐 전부(같이 끌었으면 둘 다).
2. `RunManager`가 구독해 기여 기록(`PlayerContribution`)에 `Rescues` +1 — 기존 동기화 목록에 필드 하나 추가(docs/03 표 갱신).
3. 결과 화면 줄 이름 옆 " · 구조 N" (N>0일 때만).
- RunManager.cs가 303줄 — 적립·귀환 계산·기여 부분을 `RunManager.Tally.cs`로 나눔(partial).
- 새 밸런스 수치 없음.

## 확인 계획
- 창고 2인: 클라를 끈끈이 상태로 → 호스트가 구출(서버 함수) → 호스트 쓰러뜨림 → 클라가 몸을 쥐고 쥐구멍까지 → 부활. 귀환 뒤 결과: 호스트 줄 "구조 1", 클라 줄 "구조 1". 클라 화면 결과 글자도(시험 명령 hud).
- 나눈 뒤 적립·귀환 계산 그대로(적립 +N, 들고 온 것), 오류 0.
