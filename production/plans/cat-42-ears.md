# 고양이 42 — 귀 돌리기 (2026-09-24, design/cat-ideas/13 "관심 대상이 바뀔 때 귀가 그쪽으로 돌아간다", 필러 2 읽히는 고양이)

## 목표
고양이 **귀가 관심 쪽으로 돈다**. 특히 **의심까지는 안 가는 작은 소리**(청각 임계의 절반~임계)에도 귀만 쫑긋 — 쥐는 "방금 발소리를 들을 뻔했다"를 게이지가 오르기 전에 본다. 자는 고양이도 귀는 움직인다.

## 설계
- `CatSenses.EarHeard(pos)`: 소리 전파 반경의 `catEarRadiusMul` 1.5배 안이고 크기(감각 배율 곱) ≥ 임계 × `catEarHearMul` 0.5면 발생 — 게이지는 반경 안에서만 오르므로 반경 1~1.5배 구간은 "귀만".
- `CatBrain.Ears` (호스트): `EarPoint`(Vector3)·`EarActive`(bool) NV. 소리 → 그 지점 `catEarHoldSeconds` 2s. 상태가 대상을 가지면 계속 그쪽: Chase(쫓는 쥐)·Suspicious/Search(조사 지점)·Distracted(유인 지점)·Curious(굴러가는 물건). 0.25s마다, 0.3m 넘게 바뀔 때만 NV 갱신.
- `CatVisual`(모든 클라): Ear_L·Ear_R가 몸 기준 방향으로 yaw ±80° + 앞으로 쫑긋, 부드럽게. 비활성이면 제자리. dev 로그 "고양이 귀 연출: 쫑긋"(2인 검증).
- 수치: catEarHearMul 0.5 · catEarHoldSeconds 2.

## 검증
- 순찰 중 고양이 왼쪽에서 임계 절반~임계 소리 → EarActive·EarPoint=소리 위치, 게이지 0 그대로, 귀 로컬 yaw 왼쪽(음수 큰 값). 2s 뒤 비활성·귀 제자리.
- 임계 이상 소리 → 귀 + 게이지 상승(기존 동작).
- 잠든 고양이도 귀만 움직임. 2인: 클라 귀 연출 로그·예외 0.

## 검증 결과 (2026-09-24)
- **첫 설계 수정**: "크기 임계 절반~임계"로 잡았더니 소리 모델이 반경 안은 크기 그대로·밖은 0이라 그 구간이 거의 없었다(발소리 12 @3m → 반경 1.7m 밖 → 0). → "반경 1~1.5배 = 귀만"으로.
- 순찰 고양이 왼쪽 4m 발소리 22(반경 3.1, 귀 4.6): 귀 켜짐·지점 오차 0.0·게이지 0 → 0·귀 yaw -80. 1.7s 뒤 꺼짐.
- 5m: 귀 안 움직임. 오른쪽 3m 발소리 30: 귀 +79·게이지 9.6(기존 동작).
- 잠(감각 0.5) 오른쪽 3.5m 발소리 22: 귀 +80·게이지 0·계속 잠.
- 2인: 빌드 클라 "고양이 귀 연출: 쫑긋", 예외 0.
- 미검증: 귀 회전이 화면에서 읽히는지(그레이박스 귀 크기) — 실플레이.
