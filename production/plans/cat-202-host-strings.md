# 고양이 202 — 호스트가 만든 문장도 클라 언어로 (2026-09-30, 3번째 루프)

## 왜
- 201 통째 시험 2인에서 클라 로그 "털실 샀어요 — 다음 맵 출발방에" — 호스트가 **완성한 한국어**를 RPC·NetworkVariable로 보내 클라가 영어여도 한국어로 뜬다. 벽 속 상점 "받을 것 목록"(FixedString)도 같음.

## 한 것
- `Core/Loc.Pack(한국어 틀, 값…)` — 틀과 값을 구분 문자(U+001F)로 묶음, 목록은 U+001E로 이음. `Loc.Unpack` — 받는 쪽이 틀을 자기 언어로, 값도 한국어 원문이면 번역(물건 이름), 숫자는 그대로. RPC 모양(string)은 그대로라 넷코드 변경 최소(docs/03 표 밖 동기화 추가 없음).
- 적용: 벽 속 상점 구매 결과·실패 사유(`StageShopCounter`, `StageQuota.ServerTrySpend`), 받을 것 목록(FixedString128 — 120바이트 넘기 전에 목록을 끊음, 예전엔 60자에서 글자 중간을 잘랐다), 기지 자판기 구매 결과(`VendingMachine`), 접속 거절 사유 3종(호스트 고정 문장 → 받는 쪽 `Loc.T`), "호스트와 연결이 끊겨…".
- 번역 도구 누락 검사가 `Loc.Pack("…")`도 봄. 번역 14줄 (표 402줄).

## 확인
- 에디터(한국어): Unpack 결과가 예전 문장과 같음 — "털실 샀어요 — 다음 맵 출발방에", "털실 ×2, 방울 ×1", "식량 부족 (40 필요)".
- 통째 시험 16 (2인 + 영어, 새 빌드): **90초, 5스테이지·엔딩, 호스트 화면 한국어 0종, 호스트·클라 경고·오류·예외 0**. 클라 로그 "Bought Yarn ball — waiting in the next map's start room" ×3, "Last stage — there's no next map".
- 받을 것 목록·접속 거절 사유는 화면 확인 못 함(목록은 클라 상점 창을 열어야, 거절은 5번째 접속·진행 중 참가) — 체크리스트로.
