# 고양이 65 — 새 루프 6단계: 스테이지 사이 상점 (기획, 2026-09-24)

> 근거: 팀 대화 "음식을 모은 뒤 다음 맵에서 도움이 될 만한 템을 구매(식량으로)" (`design/references/2026-09-24-team-direction.md`).
> 아래 **잠정**은 대화에 없어 기본값으로 둔 것 — 사용자 확인 필요 (체크리스트 판단 부탁에 올림).

## 규칙 (잠정)

- **어디서**: 목적지방의 상점 판매대(E). 목적지방 = 식량 창고가 있는 방.
- **무슨 돈**: `남은 식량(RunSession.Pantry)` + `이번 스테이지 초과분(창고 적립 − 할당량, 0 이상)`. 값은 남은 식량에서 먼저 빼고, 모자라면 창고 적립에서 뺀다 → 적립이 할당량 밑으로 내려가면 다시 모아야 넘어간다(선택은 팀 몫).
- **무엇을** (전리품이 아닌 도구만 — 치즈처럼 식량 가치가 있는 걸 팔면 사서 창고에 넣는 구멍이 생김):

| 물건 | 효과 (이미 있는 기능) | 값 (잠정) |
|---|---|---|
| 털실 | 던지면 고양이가 쫓음 (docs/08 유인) | 40 |
| 후추통 | 쏟으면 냄새 자국 지움·고양이 재채기 (고양이 33) | 50 |
| 레이저 포인터 | 들고 있으면 빨간 점 → 한가한 고양이가 쫓음 (고양이 41) | 80 |

- **언제 받나**: 산 물건은 **다음 맵의 출발방**에 놓인다(지금 맵에서 들고 가면 씬 전환 때 사라지므로 "택배"로). 마지막 스테이지에서 사면? — 엔딩 뒤 사라짐(판매대에 "마지막 스테이지" 표시로 막기).
- **표시**: 판매대 패널에 지갑(남은 식량 + 초과분)·물건·값·"사기", 아래에 "다음 맵에서 받을 것" 목록.

## 구현 단계

1. 물건 프리팹: 털실은 `Prefabs/Items/Lure_Yarn` 있음. 레이저·후추는 창고 데모 씬에만 있음 → 에디터 도구로 네트워크 프리팹 추출(`ZoneTools.ToPrefab`과 같은 방식).
2. 데이터 `Data/StageShopSO`(물건·값·표시 이름) — 값은 SO에(하드코딩 금지). `RunSession.PendingItems`(다음 맵 택배).
3. `World/StageShopCounter`(IInteractable, 목적지방 Depot 옆에 GridZoneBuilder가 스폰) + 구매 ServerRpc(호스트가 지갑 확인·차감·택배 추가) → EventBus 결과 → UI.
4. UI `UI/StageShopPanel`(WorldPanelKind 추가 — 자판기 ShopPanel 구조 재사용, 거울처럼 uGUI + 테마).
5. `GridZoneBuilder`: 출발방에 택배 스폰 → `RunSession.PendingItems` 비우기.
6. 확인: 1인 사기·차감 순서·할당량 밑으로 떨어지면 못 넘어감·다음 맵 출발방에 물건, 2인(클라가 사도 호스트 판정·동기화).

## 체크리스트 (예정)
- U-65 상점: 목적지방 판매대 E → 패널, 털실 사기 → 지갑 −40, 다음 맵 출발방에 털실.

## 진행 1 — 물건·목록·택배 (2026-09-24)
- `Data/StageShopSO`(Id·이름·프리팹·값·설명, `TryGet`), `GridZoneSO.Shop`, `RunSession.PendingItems`(런 초기화 때 비움).
- `Tools/RatGame/Zone/Create Stage Shop Items`: 창고 데모의 레이저·후추 → `Prefabs/Items/Shop_LaserPointer`·`Shop_PepperShaker`(머티리얼 에셋화, 네트워크 프리팹 자동 등록 2), 털실은 기존 `Lure_Yarn`. 목록 에셋 `Data/Zones/StageShop_Walls`(털실 40·후추통 50·레이저 80). 셋 다 식량 가치 0 확인.
- `GridZoneBuilder.DeliverPurchases`: 출발방 가운데 1.8m 둘레에 택배 스폰 후 목록 비움.
- 확인: 스테이지 1 중 택배 목록에 털실·레이저 → 클리어 → 스테이지 2 출발방에 둘 다(1.8m, 바닥 위), 목록 0, 로그 "택배: 출발방에 털실, 레이저 포인터".
- 테스트 절차 메모: 출발과 같은 프레임에 창고로 옮기면 "출발 뒤 한 번은 창고 밖" 규칙 때문에 귀환이 안 걸린다(실제 플레이에선 안 생김).
- 남은 것: 판매대(IInteractable)·구매 RPC·지갑 규칙·UI 패널 → 2인.
