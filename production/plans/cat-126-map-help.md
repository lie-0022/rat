# 고양이 126 — 지도에 도움이 필요한 동료 (2026-09-25)

## 왜
- 벽 속 미로에서 동료가 쓰러지거나 덫에 걸리면(혼자선 못 풀림, docs/04) 어디 있는지 찾기가 제일 어렵다. 지도(Tab, 고양이 102)엔 동료 점이 이미 있지만 상태와 상관없이 같은 색이라 누구를 구하러 갈지 안 보였다.

## 한 것
- `UI/WallsMapWidget`: 쓰러짐·덫·잡힘(Downed·Trapped·Pinned)인 쥐의 점이 **빨강으로 깜빡이고(3Hz) 크게(24px)**, 맨 위에 그린다. 풀리면 원래 색·크기.
- 상태는 이미 모두에게 동기화된 `PlayerCondition.State`를 읽기만 — 새 동기화 없음. 색·깜빡임 속도는 인스펙터 값.
- 개발 로그 "지도 도움 표시: client N 상태" (도움이 필요해지는 순간 한 번, 2인 검증용).

## 같이 찾은 버그 (고침)
- 쓰러진 동안 콘솔에 "Setting linear velocity of a kinematic body is not supported." 오류가 **초당 약 10번**. 쓰러지면 쥐 몸이 키네마틱이 되는데(PlayerDownedBody), 시점이 대리 몸을 따라가게 0.1초마다 부르는 텔레포트가 속도를 0으로 쓰고 있었음(고양이 46부터 있던 것 — 소크는 "예외"만 세서 못 봄).
- 고침: `PlayerController.Place`·바닥 대기에서 키네마틱이면 속도 쓰기를 건너뜀.

## 확인
| 확인 | 결과 |
|---|---|
| 1인 덫 1.2초 | 빨강 138/286프레임(깜빡임 반반), 크기 24 |
| 1인 쓰러짐 1.2초 | 빨강 94/200 |
| 살린 뒤 | 흰색·18로 돌아옴 |
| 쓰러짐 3초 오류 | 0 (고치기 전 초당 ~10) |
| 대리 몸 1.5m 옮김 | 시점이 따라감(평면 거리 0.00), 오류 0 |
| 2인 (호스트 에디터 + 빌드 클라) | 클라 로그 "지도 도움 표시: client 0 Downed" → "client 2 Trapped" → "client 2 Downed", 클라 쓰러짐 3초 동안 키네마틱 오류 0·예외 0, 호스트 오류 0 |
