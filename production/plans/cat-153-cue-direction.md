# 고양이 153 — 고양이 소리 자막에 방향 (2026-09-26, 3번째 루프)

## 왜
- 고양이 소리 자막(루틴 예고·아기 부름·졸음·코골이)은 소리 대신이지만 **어느 쪽인지**가 없다. 진짜 소리라면 방향이 들린다 — 넓어진 벽 속(141)에선 "어디서"가 더 중요.
- 자막에 방향을 붙이는 건 게임 자막의 흔한 방식(청각 보조)이기도 하다.

## 규칙
- 자막 끝에 " · 왼쪽 뒤"처럼 **내 카메라 기준 8방향**(앞·오른쪽 앞·오른쪽·오른쪽 뒤·뒤·왼쪽 뒤·왼쪽·왼쪽 앞). 들을 때 한 번 정해짐(따라 돌지 않음).
- **매복 "(츄릅… 어디선가)"는 방향 없음** — 어디 숨었는지 모르는 게 매복의 핵심(docs/07 Ambush).
- 같은 문구 연속 금지는 방향 빼고 비교(방향만 달라도 연속이면 안 띄움 — 예전과 같음).
- UI만(ToastWidget), 새 수치 없음.

## 확인 계획
- 1인: 카메라 방향을 돌려가며 예고 → 방향 문구가 맞는지(앞/오른쪽/뒤/왼쪽), 매복은 방향 없음.
- 토스트 한 줄에 들어가는지 스크린샷(가장 긴 문구).

## 확인 (2026-09-26, 1인, 스테이지 1 — UI만, 넷코드 변화 없음)
- 고양이 멈추고 쥐를 고양이 남쪽 10m에 두고 카메라 방향만 바꿔 예고:

| 카메라 | 기대 | 자막 |
|---|---|---|
| 북(0°) | 앞 | "(배 꼬르륵 — 고양이가 밥 먹으러) · 앞" |
| 동(90°) | 왼쪽 | "(할짝할짝 — 물 마시러) · 왼쪽" |
| 남(180°) | 뒤 | "(창가 쪽 기지개 — 햇볕 쬐러) · 뒤" |
| 서(270°) | 오른쪽 | "(쩌억 하품 — 자러 간다) · 오른쪽" |
| 북동(45°) | 왼쪽 앞 | "(모래 긁는 소리… 곧 우다다!) · 왼쪽 앞" |
| 매복 | 방향 없음 | "(츄릅… 어디선가)" |

- 바꾼 것: 가장 긴 문구(순찰꾼 졸음 + "오른쪽 뒤")가 두 줄로 꺾여 "뒤"만 아랫줄(`cat-153/wrap_before.png`) → `Hud.prefab` 토스트 글자를 **한 줄 + 자동 크기 24→최소 17**로(프리팹 값 3개만). 긴 문구만 살짝 작아지고 나머지는 그대로 24(`cat-153/one_line_after.png`).
