# 고양이 130 — 빌드 클라 첫 접속이 매번 실패하던 것 (2026-09-25)

- 증상: 오늘 에디터 호스트 + 빌드 클라 `-autojoin` 시험마다 첫 시도 "Failed to connect to server." → 재시도 2~3번째에 붙음. 호스트엔 연결 수가 하나 더(유령) 남기도 함.
- 원인: UnityTransport 참가 예산이 10회×0.5초 ≈ 5초(메뉴가 참가 실패를 빨리 알리게 — 고양이 이전 메인 메뉴 작업의 결정). 에디터 플레이 모드 호스트는 핸드셰이크가 느려 이 안에 못 끝냄.
- 확인: **빌드 호스트(`-autohost`) + 빌드 클라(`-autojoin`)는 첫 시도에 바로 붙음**(호스트 "클라 접속: client 1", 클라 재시도 없음). 실제 참가는 빌드끼리·Steam(Facepunch)이라 해당 없음.
- 결정: 코드 안 고침(메뉴 5초 안내를 지키고, 에디터 시험은 재시도로 충분). docs/03에 기록. 에디터 호스트 시험 절차는 그대로 "재시도를 기다린다".
