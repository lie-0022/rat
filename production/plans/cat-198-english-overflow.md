# 고양이 198 — 영어 모드 글자 넘침 검사 (2026-09-30, 3번째 루프)

## 왜
- 188~197에서 화면 글자를 영어로 옮겼다. 영어는 한국어보다 글자 수가 약 2배 — 알림 칸(522×56, 자동 크기 24→최소 17)은 154번에서 "40자 넘으면 줄바꿈"으로 겨우 맞춘 칸이다.

## 방법 (에디터 혼자, English)
- 켜진 TMP 글자 전부: `isTextOverflowing` · 줄바꿈 없는 글자의 `preferredWidth > 칸 너비` · 자동 크기가 최소에 붙음.
- 알림은 떠 있는 시간이 짧아 **알림 틀을 복제해 문장을 넣고 재는** 방식. 번역 표 383줄 하나씩 → 0개. 그런데 실제 안내는 넘침 → **알림 하나에 문장을 이어 붙이는 조합**이 문제였다(하나씩은 다 들어감).
