# 고양이 25 — 고양이 디버그 오버레이 (F3) (2026-09-24, 개발 도구)

## 목표
고양이 상태가 20개 넘게 쌓였다. 사용자가 직접 플레이 테스트할 때 "지금 고양이가 뭘 하는지·왜 그러는지"를 바로 보게 한다. 개발 빌드·에디터에서만.

## 설계
- `UI/CatDebugOverlay` (IMGUI — docs/12의 DEV 넷 패널과 같은 개발 전용 예외): `RuntimeInitializeOnLoadMethod`로 개발 빌드·에디터에서만 자동 생성(DontDestroyOnLoad). **F3**으로 켜고 끔(기본 꺼짐).
- 화면 오른쪽 위 목록 — 고양이마다: 이름·성격·상태(실패 종류·잠 단계)·게이지·타깃·찍힌 쥐·예민·숨김(부재/매복).
- 호스트면 추가: 경계도 디렉터 모드·긴장, 고양이 관계, 집주인 이벤트 남은 수.
- 월드 라벨: 고양이 머리 위에 "상태 · 게이지".
- 읽기만 한다(NetworkVariable·공개 프로퍼티) — 규칙 3.

## 검증
- F3 토글(입력 주입) → 목록·라벨 표시 스크린샷. 2인 클라에서 NV 정보 표시(로그).

## 검증 결과 (2026-09-24)
- 플레이 시작 시 자동 생성(에디터), 기본 꺼짐 → F3 입력 주입 → 켜짐.
- 스크린샷: 오른쪽 위 "고양이 디버그 (F3) / 디렉터 Buildup · 긴장 13 / 집주인 남은 0건 / Cat 게으름뱅이 Patrol · 게이지 0 / 예민(디렉터)", 고양이 머리 위 "Patrol · 0". IMGUI 한글 정상.
- 2인 생략: 네트워크 변경 없음(로컬 표시, 기존 NV만 읽음). 클라에선 호스트 전용 줄(디렉터·관계·집주인)이 빠진다.
