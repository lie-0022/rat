# 고양이 31 — 어둠 구역 LightZone (2026-09-24, docs/07 "어둠", docs/10 DarkZones)

## 목표
docs/07에 있던 사양 "방의 LightZone 볼륨 안이면 viewDistance 50%"를 실제로. **어두운 곳이 안전**을 시스템으로 — 쥐가 경로를 고를 이유. 다음 작업(고양이 32 불 켜짐)의 토대.

## 설계
- `World/LightZone` (NetworkBehaviour, 박스 트리거): `Lit` NV(false = 어둠). 정적 목록 `All`, `static bool IsDark(Vector3 pos)` — 꺼진 구역 박스 안이면 true.
- 판정은 **쥐 위치** 기준: 고양이가 밝은 곳에 있어도 어둠 속 쥐는 절반 거리에서만 보인다. 웅크림(×0.5)과 곱해진다 → 어둠+웅크림 = 8m × 0.25 = 2m.
- `CatSenses.VisionTick`: `LightZone.IsDark(쥐)`면 viewDist × `catDarkViewMultiplier` 0.5 (BalanceConfig).
- 연출: 바닥에 어두운 얇은 판(콜라이더 없음) — `Lit`이면 숨김(모든 클라). 고양이 32에서 불 켜짐이 쓴다.
- 쥐 HUD는 추가하지 않는다 — 바닥 판이 곧 표시다.
- 데모 레이아웃: 어둠 구역 1개 — 동쪽 (13, 0, -2) 8×8 m.

## 검증
- 밝은 곳 6m 정면 쥐 → 보임(게이지 상승), 어둠 속 6m → 안 보임, 어둠 속 3.5m → 보임.
- 어둠 + 웅크림 3m → 안 보임, 1.8m → 보임.
- `Lit` true → 6m 다시 보임, 판 숨김.
- 2인: 클라에 판 보임·Lit 복제(로그).
