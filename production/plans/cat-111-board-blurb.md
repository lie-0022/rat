# 고양이 111 — 목적지 게시판 설명 한 줄 (2026-09-25)

- 기지 게시판이 목적지 이름만 보여 줘서 "벽 속(생성)"이 새 루프라는 걸 모른다.
- `DeparturePad._stageBlurbs`(이름과 같은 순서, 씬에 없던 필드라 코드 기본값): 창고 "고양이 기능 모음 — 한 판", 부엌 "무작위 부엌 — 한 판", 벽 속 "새 루프 · 5스테이지 · 식량 할당량 · 목적지 상점 · 엔딩". `StageBoard`가 셋째 줄(60%)로.
- 확인: 기지에서 벽 속 선택 → 게시판 정면 스크린샷, 세 줄 모두 판 안에.
- 기본 목적지를 벽 속으로 바꾸는 건 판단 부탁 8 그대로(사용자 결정).
