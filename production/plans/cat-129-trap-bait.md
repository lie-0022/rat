# 고양이 129 — 쥐덫 미끼 (2026-09-25)

## 왜
- 기능 계획표에 남아 있던 "쥐덫 치즈". 은신·위험 대비 보상(필러)에 맞고 규칙이 한 줄: **미끼는 웅크리고 살금살금.**
- 맵 식량 총량을 안 늘리려고 새로 만들지 않고 같은 방 음식을 옮긴다 (판단 부탁 7 — 할당량이 쉬움 — 과 안 엮이게).

## 규칙
| 상황 | 결과 |
|---|---|
| 서서 미끼 집기 | 격발(소음 80, 기존 쥐덫 소리) + 집은 쥐 기절 2.5초 + 든 것 떨어뜨림, "탁! 미끼는 웅크리고(Ctrl) 살금살금" |
| 웅크려 집기 | 쥐덫 그대로, 미끼만 가져감, "살금살금 — 미끼만 쏙!" |
| 미끼가 판(쥐덫 박스) 밖으로 밀림 | 헛격발 — 아무도 안 다침(던지거나 밀어 치우는 방법) |
| 판을 밟음 | 원래대로 다운 |

## 구현
- `World/MouseTrap`: `ServerSetBait`, 호스트 Update에서 미끼 감시(캐리어 생기면 웅크림 판정 — 스케일, PlayerScent·소음과 같은 방식), 결과는 집은 쥐에게만 ClientRpc → `EventBus.TrapBait` → ToastWidget.
- `Run/GridZoneBuilder.Bait.cs`(새 partial): 채우기 뒤 쥐덫마다 확률로 가장 가까운(6m, 벽 너머 제외) 작은 음식(무겁지 않고 가치 > 0)을 옮김. 로그 "쥐덫 미끼 N/M".
- 수치: `BalanceConfigSO.trapBaitStunSeconds` 2.5, `GridZoneSO.TrapBaitChance` 0.5·`TrapBaitSearchMeters` 6 (docs/10 표).
- 시험 도구: `PlayerController.DevForcedCrouch`, DevRemoteControl `crouch`/`stand`.
- 바꾼 것: 처음엔 "0.35m 밀리면 헛격발"이었는데, 시험에서 3m/s로 민 미끼가 0.34m에서 멈춰 안 터짐 → "판 밖으로 나가면"으로 바꾸고 거리 수치는 뺐다.

## 확인
| 확인 | 결과 |
|---|---|
| 배치 | 스테이지 5 덫 대방출에서 "쥐덫 미끼 6/10", 다른 맵 "5/6"·"2/7"(가까운 작은 음식 없으면 못 얹음) |
| 1인 서서 | 쥐덫 꺼짐, 호스트 Stunned, 안 들고 있음 → 3초 뒤 Active |
| 1인 웅크려 | 쥐덫 그대로, 들고 있음, Active |
| 1인 밀기 | 헛격발, 호스트 무사 |
| 2인 (빌드 클라) | 클라 서서 → 호스트: 쥐덫 꺼짐·클라 Stunned·안 들고 있음, 클라 로그 "쥐덫 미끼 연출: 탁". 클라 웅크려(스케일 0.30) → 쥐덫 그대로·클라 들고 있음, 클라 "살금살금". 클라 오류 0 |
