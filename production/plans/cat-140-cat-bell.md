# 고양이 140 — 고양이 방울 (상점 물건, 2026-09-25, 3번째 루프)

## 왜
- 목적지 상점 물건이 셋(털실·후추통·레이저) 다 "유인·지우기"다. **정보를 사는 물건**이 하나 있으면 식량 쓰임이 넓어진다(판단 6 "물건 늘리기는 기획에서").
- "고양이 목에 방울 달기" — 쥐 우화 그대로라 컨셉에 딱 맞고, 던져 맞혀야 해서 손맛·실패(웃김)도 있다. 전투 아님(가드레일 OK).

## 규칙 (잠정 — 체크리스트 판단 부탁에 올림)
- 상점 "방울" **60**(털실 40 < 방울 60 < 레이저 80). 다음 맵 출발방에 택배.
- **던진 뒤 1.5초 동안** 방울이 날아가거나 구르다 고양이 **1m 안(수평)**을 지나면 그 고양이 목에 방울이 달린다(이번 스테이지 끝까지). 빗나가면 그냥 바닥에 굴러 있음 — 주워 다시 던질 수 있다.
- 방울 단 고양이: 목에 금색 방울이 보이고, **Tab 지도에 주황 점**으로 팀 모두에게 보인다(어디 있는지 알고 피해 다님). 고양이 행동은 그대로(맞아도 모름 — 방울이 가벼워서).
- 달리는 순간 전원 토스트 "방울 달았다! Tab 지도에 고양이가 보여요".

## 구현
1. `World/CatBell`(물건 쪽, 호스트): `OnCollisionEnter` + `IsRecentlyThrown` — 부딪힌 게 고양이면 그 고양이, 아니면 착지 지점 `catBellHitMeters` 1m 안 가장 가까운 고양이 → `CatBrain.ServerAttachBell()` → 물건 `DespawnSafe`.
2. `AI/CatBrain.Bell.cs`(partial): NV `Belled`(서버 쓰기) — docs/03 표에 추가. 모든 클라에서 값이 바뀌면 목에 금색 공 + `EventBus.CatBelled`.
3. `UI/WallsMapWidget`: 방울 단 고양이 = 주황 점. `UI/ToastWidget`: CatBelled 토스트.
4. 에디터 도구 `Tools/RatGame/Zone/Create Cat Bell`: 털실 프리팹을 본떠 `Prefabs/Items/Shop_CatBell`(금색 머티리얼 에셋, CatLure → CatBell) + 상점 목록에 "bell" 60 추가.
5. F4: 고양이마다 "방울 달기" 버튼(던지기 없이 표시·지도 확인용).
6. 수치: `BalanceConfigSO.catBellHitMeters` 1, 값은 상점 SO. docs/08(상점)·docs/12(지도)·docs/03(NV) 갱신.

## 확인 계획
- 1인: 방울을 고양이 쪽으로 던짐(호스트가 ServerRelease thrown) → Belled, 물건 사라짐, 지도 주황 점, 토스트. 빗나감(고양이 5m 밖) → 안 달림, 물건 남음.
- 2인: 클라 화면에서 목 방울·지도 주황 점·토스트, 클라가 던져도 호스트 판정.
- 상점: 목록에 "방울 60", 구매 → 다음 맵 택배.
