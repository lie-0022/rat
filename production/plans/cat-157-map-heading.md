# 고양이 157 — Tab 지도에 내가 보는 방향 (2026-09-26, 3번째 루프)

## 왜
- Tab 지도(고양이 102)에서 나는 흰 점뿐 — 어느 쪽을 보고 있는지 몰라서 지도를 보고 "저 방으로" 정해도 화면에서 어느 쪽인지 다시 헤맨다. 맵이 2배가 된 뒤(141) 더 불편.

## 할 것
- 내 점 앞에 **짧은 흰 막대**(폭 6·길이 14px, 검은 테두리, 화면 px 고정 — 151과 같은 이유)를 카메라가 보는 쪽으로. 지도는 북쪽(월드 +z)이 위라 막대가 곧 나침반.
- UI만(WallsMapWidget), 로컬, 새 수치 없음.

## 확인 계획
- 1인: 카메라 북·동·남·서로 돌리며 Tab 스크린샷 → 막대가 위·오른쪽·아래·왼쪽.
