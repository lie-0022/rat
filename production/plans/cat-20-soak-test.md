# 고양이 20 — 통합 소크 테스트 (2026-09-24)

## 목표
고양이 1~19로 상태 17개·특이 행동 10여 개가 쌓였다. 기능마다 단독 검증은 했지만 **서로 얽혀 오래 돌 때** 생기는 문제(갇힘·무한 루프·예외·상태 누수)는 안 봤다. 새 기능 대신 한 판을 길게 자동으로 돌려 본다.

## 방법 (에디터 호스트 1인, 필요하면 2마리)
- 쥐 자동 배회(`PlayerController.DevAutoWander`), `Time.timeScale` 3 — 실시간 150s ≈ 게임 450s.
- 0.25s마다 기록: 고양이 상태·실패 종류·위치·쥐 상태.
- 중간 사건: 60s 부르기, 120s 밥 시간(집주인 디렉터 수동 트리거 — Phase를 StageActive로 바꾸면 귀환·결과 화면으로 씬이 넘어갈 수 있어 Ready 유지).
- 집계:
  - 상태별 방문 횟수·최장 연속 시간(게임 초)
  - **갇힘**: 이동해야 하는 상태(Return·Chase·Track·Suspicious·Search·Curious·Zoomies·Patrol 비머무름)에서 게임 15s 동안 0.3m 미만 이동
  - 콘솔 에러·예외(Application.logMessageReceived)
  - 쥐 다운 횟수, 성격
- 2부: 두 번째 고양이 스폰 후 같은 방식(싸움·관계 포함).

## 판정
- 예외 0, 갇힘 0이 목표. 나오면 원인 수정 → 재실행.
- 결과 표는 이 문서와 세션 로그에.
