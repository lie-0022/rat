# 고양이 123 — 배회 시험 쥐가 벽 속을 실제로 돌아다니게 (2026-09-25)

> 근거: `-autowander`(펄린 노이즈 방향)는 문 하나짜리 출발방에서 거의 못 나가서 10분 소크(94)가 실제 미로를 안 거쳤다.

- `Player/DevWallsWander`: 격자 방이 있으면 무작위 방을 골라 `GridRoute.TryNextHintTo`(킁킁 길 찾기를 목적지 대신 아무 방으로 — 새 오버로드)로 문→문, 도착·25초 막힘이면 다음 방. 문 앞에 닿으면 아직 방 안으로 쳐서 같은 문을 또 가리키는 문제 → 0.6m 안이면 가던 방향으로 밀고 지나감.
- `PlayerController`: DevAutoWander이고 위 방향이 있으면 월드 방향으로(DevForcedInput과 같은 자리).
- 확인: 호스트 쥐 배회 90초 — 처음엔 출발방 문 앞에서 멈춤(1방) → 고친 뒤 15초 5방·30초 7방, 90초에 고양이에게 잡혀 다운(시험 쥐가 실제 위험을 겪음).
