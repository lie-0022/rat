# 고양이 162 — 킁킁 쿨다운 중 누르면 남은 시간 (2026-09-26, 3번째 루프)

## 왜
- R(킁킁)은 쿨다운 10초. 쿨다운 중에 누르면 **아무 일도 안 일어나서** 키가 안 먹은 건지 헷갈린다(150 뒤 킁킁을 더 자주 쓰게 됨).

## 규칙
- 쿨다운 중 R → 토스트 "(킁킁… 코가 아직 얼얼 — 6초)"(남은 초 올림). 같은 안내는 1초에 한 번만(연타 도배 방지). 로컬, 새 수치 없음.
- 흐름: `PlayerSniff.TrySniff`(소유 클라) → `EventBus.SniffCooldown(남은 초)` → `ToastWidget`(소리 자막 파일 옆, 규칙 3).

## 확인 계획
- 1인: 킁킁 직후 R 연타 → 토스트 1초에 한 번, 숫자 줄어듦. 10초 뒤 R → 정상 킁킁.
