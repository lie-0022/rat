# 고양이 151 — Tab 지도 출구 선이 커진 맵에서 안 보이던 것 (2026-09-26, 3번째 루프)

## 왜
- Tab 지도(고양이 102)의 "방마다 열린 문 쪽 짧은 선"은 길이 1.6m·폭 0.9m를 **m로** 그려 지도 배율을 곱했다. 141에서 맵이 2배가 되자 지도 배율이 절반 → 선이 1~2px로 줄어 거의 안 보였다(아래 전 사진). 가 본 적 없는 출구를 보는 게 이 선의 목적이라 기능이 사실상 꺼진 셈.

## 한 것
- 출구 선을 **화면 px 고정**(길이 14·폭 9) — 방 가장자리 위치만 지도 배율, 선 크기는 맵 크기와 상관없이 같다. 코드 상수(표시용, 밸런스 수치 아님).
