# 고양이 124 — 배회 쥐 2마리가 실제로 돌아다니는 벽 속 소크 (2026-09-25)

> 근거: 고양이 123으로 배회 쥐가 미로를 다닌다. 94의 10분 소크는 쥐가 출발방에만 있어 고양이·함정·배관·매복이 실제로 쥐와 부딪히지 않았다.

## 방법
- 호스트(에디터, 가만히) + 빌드 클라 2(`-autowander`, 로그 따로), 스테이지 5 다시 로드 → 600초 또는 스테이지가 끝날 때까지(둘 다 다운 = 전멸 흐름도 확인).
- 5초마다 고양이 갇힘(60초 0.5m 미만), 60초마다 요약, 로그 키워드 수(덮치기·매복·다운·함정·집주인 사건·전멸 등), 예외.

## 결과
- 601초, 호스트·클라 둘 다 예외 0, 고양이 갇힘 0. 오늘의 집 "집주인 외출"(사건 0 예약 — 집주인 알림 1은 끝난 사건 로그), 고양이 3.
- 배회 쥐가 실제로 부딪힘: 추격 16·잡기 12·끈끈이 2. 241초에 두 클라 쥐 모두 다운/속박 → 이후 대부분 2명 비활성(시험 쥐는 서로 구하지 않음). 호스트 쥐가 살아 있어 전멸 아님 → 스테이지 계속(맞는 동작).
- 스테이지 5 로드 때 유령 연결 1개가 있었는데 정리(20초) 뒤 바로 맵 짓기 — 고양이 121 문이 실제로 동작.
