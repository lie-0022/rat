# 고양이 139 — 핑한 물건 이름·가치 (2026-09-25, 3번째 루프)

## 왜
- 핑은 "여기"만 알려 준다. 벽 속 미로에서 "저거 비싸, 가져가자"를 말없이 전하려면 무엇을 찍었는지가 보이면 좋다(협동·소통, 필러).

## 한 것
- `UI/PingMarkerWidget.OnPing`: 핑 지점에서 가장 가까운 물건(콜라이더 표면까지 `pingItemSnapMeters` 0.6m 안, 주머니 속 제외)을 찾아 이름 상자에 `· 이름 가치`를 덧붙임(가치 0이면 이름만). 이름 상자는 원래 글자 길이에 맞춰 늘어남.
- 물건 위치·가치(내구도 반영 EffectiveValue)는 모든 클라에 이미 있음 → **각자 계산, 새 동기화 없음**. 수치는 `BalanceConfigSO.pingItemSnapMeters`.

## 확인
| 확인 | 결과 |
|---|---|
| 1인 실제 핑 | 참치캔에 카메라 조준 → TryPing → "회색 쥐 (나) · 참치캔 38", 스크린샷 `cat-139/ping_item.png`(글자 넘침 없음) |
| 2인 | 호스트가 포도알 핑 → 클라 로그 "핑 물건 연출: 포도알 10", 오류 0 |
