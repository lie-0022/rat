# 13 — 관심 생태계

**한 줄:** 털실·캣닢·쿠키를 각각 특수 규칙으로 두지 말고, 고양이의 **"관심 점수"** 하나로 통합한다. 굴러가는 캔, 레이저, 흔들리는 끈, 사료, 초인종까지 같은 저울에 올린다.

## 왜 재밌나
- 지금 유인은 3종 각각 하드코딩(Distracted 8s/15s, 웨이포인트 삽입). 통합하면 **아이템끼리 조합**이 생긴다: 캣닢으로 붙잡아 두고 레이저로 방 밖까지 끌고 가기.
- 쥐의 도구 상자가 "무엇이 고양이의 관심을 얼마나 오래 사는가"라는 **하나의 언어**가 된다 — 배우기 쉽고 깊다.
- 고양이가 여러 자극 사이에서 **갈등하는 모습**이 귀엽다(캔이냐 레이저냐).

## 플레이어가 겪는 장면
- 고양이 머리 위에 관심 대상이 바뀔 때 **귀가 그쪽으로 돌아간다**. 쥐는 귀를 보고 "지금 캔에 꽂혔다"를 안다.
- 레이저 포인터(상점 아이템)를 벽에 쏜다. 고양이가 점을 쫓아 방을 나간다. 레이저를 **끄면** 고양이가 두리번(관심 잔여 5s) 후 돌아온다 — 조종 시간 = 배터리 20s.
- 캣닢 위에서 뒹구는 고양이 옆으로 캔이 굴러간다 → 무시(캣닢 관심이 더 큼). 접시가 깨진다 → 그건 관심이 아니라 **의심**이라 즉시 깬다. 관심과 의심은 다른 축.
- 초인종(맵 오브젝트)을 누르면 집주인 이벤트(10) — 관심 축의 최상위 카드, 런당 1회.

## 규칙 스케치
- 모든 자극은 `Attention{pos, score, decayPerSec, kind, source}`. 고양이는 시야/청각 안의 자극 중 **점수 최대**를 쫓는다(`Curious/Distracted` 통합 → `Attend` 상태). 점수는 시간에 따라 감소, 0이면 잊음.
- **의심(Suspicion)은 별도 축**: 플레이어 목격·Break/Trap 소음은 관심이 아니라 의심. 의심 ≥ 임계면 관심을 전부 무시(추격 우선). 즉 "고양이가 놀고 있을 때만 유인이 먹힌다"는 지금 규칙 유지.
- **지루함**: 같은 kind에 60s 안에 3회 반응하면 그 kind 점수 0.5× (무한 캔 굴리기 방지). 05 앙심 대상이 낸 자극은 0.

| 자극 | 점수 | 지속(감쇠) | 비고 |
|---|---|---|---|
| 굴러가는 물건(03) | 30 + 속도×5 | 10s | 멈추면 급감 |
| 털실뭉치 | 60 | 8s (놀이 애니) | 지금과 동일 |
| 캣닢 | 90 | 15s, 반경 3m 진입 시 | 취한 뒤 비틀거림(11) |
| 쿠키 부스러기 | 40 | 경유 1회 | 순찰 경로 삽입 → 이제 "낮은 관심이 오래" |
| 레이저 포인터(신규, 상점 60) | 80 | 켜져 있는 동안 + 5s | 쥐가 조준 조작, 배터리 20s, 벽·천장 OK |
| 흔들리는 끈(신규, 설치형 30) | 50 | 30s, 주기적 흔들림 | 근처 지나갈 때마다 재점화 |
| 사료 붓기(신규, 20) | 70 | 25s (밥 루틴 02 강제) | 부엌 그릇에만 |
| 초인종(맵) | 100 | 10 집주인 이벤트 | 런당 1회 |

- 표시: 고양이 귀 방향 + HUD 의심 표시 옆 작은 "♪"(관심 중) — 필러 2.

## 쥐가 써먹을 틈
- **릴레이**: 캣닢(붙잡기) → 레이저(끌고 가기) → 끈(붙잡아 두기). 도구 3개로 고양이를 방 두 개 밖까지 보낸다.
- **경제**: 유인 아이템은 상점 소모품(docs/08 인벤 슬롯) — 슬롯을 전리품 대신 도구로 채우는 트레이드.
- **공짜 도구**: 굴러가는 전리품은 늘 있다. 돈 없는 팀의 유인 = 포도알.

## 수치 초안
- 위 표 + `BoredomWindowSeconds 60`, `BoredomMul 0.5`, `LaserBatterySeconds 20`, `StringSeconds 30`.

## 구현 메모
- `CatLure`(docs/07)를 `AttentionSystem`(정적, 호스트, NoiseSystem과 같은 모양)으로 일반화. 기존 3종은 점수·감쇠 값으로 이식 — 동작 회귀 없이.
- `Curious`(03)와 `Distracted`를 `Attend` 하나로 합친다(연출은 kind별).
- 레이저는 쥐가 든 아이템의 **조준 레이 히트 지점**을 매 프레임 `Attention`으로 갱신 — 소유 클라 → ServerRpc 10Hz.

## 리스크
- 도구가 세지면 은신이 도구 게임이 된다 → 소모품 가격·슬롯 비용 + 의심 축 우선 + 지루함으로 제한.
- 통합 리팩터가 기존 유인 동작을 바꿀 수 있음 → 3종 값을 먼저 옮기고 회귀 확인 후 신규 추가.

## 궁합
- 03 호기심(굴러가는 물건 = 자연 자극), 07 두 마리(둘을 한 방으로), 10 집주인(초인종), 02 루틴(사료), 05 앙심(무시 규칙).
