# 고양이 로직 아이디어 모음 (2026-09-17)

현재 고양이(docs/07)는 **순찰 → 의심 → 추격 → 포획 → 복귀** 한 줄 FSM + 유인 아이템 3종. 잘 돌아가지만 "고양이가 한 마리의 캐릭터"로 느껴지진 않는다.
여기 안들은 그 위에 얹을 수 있는 방향들이다. **안 하나 = 파일 하나**, 각 안은 같은 틀로 쓴다:

> 한 줄 · 왜 재밌나(필러) · 플레이어가 겪는 장면 · 규칙 스케치 · 쥐가 써먹을 틈(카운터플레이) · 수치 초안 · 구현 메모(기존 FSM 어디에 붙나) · 리스크 · 궁합

판단 기준은 docs/00 필러 4개다: ① 물리 운반이 코어 ② 은신 긴장감 — **고양이 상태가 항상 읽혀야 한다** ③ 협동 강제 ④ 귀엽고 댕청하게. 전투·PvP·절차지형은 스코프 밖(가드레일).

## 추천 묶음 (한 번에 다 하지 말 것)

- **묶음 A — 캐릭터 만들기 (작고 빠름)**: 01 성격 + 08 잠의 단계 + 11 댕청한 실패. 코드는 수치 프로필과 상태 2~3개 추가. 고양이가 "한 마리"가 된다.
- **묶음 B — 판 흔들기**: 03 호기심 + 04 가지고 놀기 + 14 숨을 곳. 추격의 앞뒤가 풍부해지고 협동 장면이 늘어난다.
- **묶음 C — 세계 만들기 (아트·맵 뒤)**: 02 루틴 + 09 환경 + 10 집주인. 방 모듈(docs/10)과 애니메이션이 있어야 산다.
- **가로축**: 12 디렉터와 13 관심 생태계는 다른 안들을 묶는 밑바탕 — 안이 3개 이상 들어간 뒤에 넣는 게 맞다.
