# 04 — 가지고 놀기

**한 줄:** 고양이는 잡은 쥐를 바로 끝내지 않는다. **툭툭 굴리고, 물고 옮기고, 놓아주고 다시 잡는다.** 그동안 동료에게 구출 창이 열린다.

## 왜 재밌나
- 지금은 Capture = 즉시 Downed → 동료가 쥐구멍까지 옮겨야 산다(docs/09). 그 앞에 **"아직 안 끝났다"** 구간을 넣으면 필러 3(협동 강제)의 장면이 두 배가 된다.
- 고양이가 진짜 고양이처럼 군다(놀다가 흥미 잃음) — 무섭고 웃기다(필러 4).
- 잡힌 사람도 할 게 생긴다: 버둥거리기, 찍찍 소리로 위치 알리기.

## 플레이어가 겪는 장면
- 잡힌 쥐 화면: 고양이 앞발 사이에서 **뒤집힌 채** 하늘을 본다. "찍찍(Q)"으로 소리를 낼 수 있다 — 동료에게 위치를 알리지만 고양이 관심도 올린다.
- 고양이가 쥐를 **물고 창가로 옮긴다**(자기 자리로 전리품 가져가기). 동료는 창가 방향을 보고 달린다.
- 고양이가 쥐를 **놓고 한 발 물러선다**(놀이). 이때 3초 안에 달리면 도망칠 수 있다 — 근데 고양이는 더 빠르게 다시 덮친다. 동료가 그 3초에 **캔을 굴리면**(03) 고양이가 그쪽으로 고개를 돌린다.
- 놀이가 끝나면(관심 소진 or 40초) 진짜 Downed. 그때부터 기존 규칙(운반해서 구출).

## 규칙 스케치
새 상태 `Toying` (Capture 성공 뒤, Downed 대신):
```
Capture 명중 → Toying(피해자 = Pinned: 조작 불가, 찍찍만)
  Toying 루프 (총 ToySeconds 40, 관심 게이지 100에서 시작):
    Bat  (2s): 앞발로 툭툭 — 피해자 위치 살짝 이동 (물리 임펄스)
    Carry(3~6s): 물고 CatSpot(창가/침대)로 이동 — 피해자는 고양이에 붙음
    Release(3s): 놓고 한 발 물러남 — 피해자 Pinned 해제, 달리면 Escape 시도
      · 피해자 3s 안에 2m 이상 벗어남 → 고양이 Pounce(1.2×속도) 재포획 or 놓침(→ Chase)
    관심 -20/루프. 외부 자극(다른 쥐 목격, 03 호기심 대상) → 관심 -40
  관심 ≤ 0 → 하품 → Return (피해자 Pinned 해제, 상태 Active! — 살아남음)
  ToySeconds 만료 → 진짜 Downed → Return
```
- **구출 개입**: Toying 중 다른 쥐가 고양이를 목격되게 하면(달리기·소음) 고양이가 그쪽 Chase → 피해자 해제(관심 -100). 즉 **미끼 역할**이 생긴다. 끈끈이 구출(E 홀드)은 쓰지 않는다 — 고양이 옆에서 1.5초 서 있는 건 이미 다른 위험.
- 솔로: Toying 없이 즉시 Downed → 전멸(지금과 같음). 놀이는 동료가 있을 때만 의미가 있다.

## 쥐가 써먹을 틈
- 잡힌 사람: Release 타이밍에 **반대 방향** 달리기 + 찍찍으로 동료 유도. 버둥거리기(좌우 연타)로 Bat 위치를 살짝 조종해 쥐구멍 쪽으로 굴러가기(가능하면 웃김).
- 동료: 미끼가 되거나(03 캔 굴리기, 소음), 고양이가 Carry로 이동하는 동안 **원래 자리의 물건을 털기**.
- 집단 판단: "구하러 갈까, 이 틈에 털까" — 협동 게임의 갈등 한 스푼.

## 수치 초안
- `ToySeconds 40`, `ToyInterest 100`, `ToyLoopDrain 20`, `ToyDistractDrain 40`, `ReleaseWindowSeconds 3`, `PounceSpeedMul 1.2`.

## 구현 메모
- `PlayerCondition`에 `Pinned` 상태 추가(enum append-only). 이동·잡기 차단은 Downed와 같고 찍찍만 허용.
- Carry 구간은 피해자 `NetworkTransform`을 고양이 자식으로 — 플레이어는 소유 클라 권한(docs/03 예외)이라 **호스트가 소유 클라에 위치를 밀어주는 RPC** 필요(TeleportClientRpc 확장). 가장 어려운 부분.
- 피해자 카메라: 뒤집힌 1인칭이 웃기지만 어지러울 수 있다 → 옵션.

## 리스크
- 잡혀 있는 40초가 지루하면 최악 → 찍찍·버둥·Release 창처럼 **할 일**이 있어야 한다. 안 되면 20초.
- 고양이가 놀다가 놓아주는 게 너무 잦으면 잡히는 게 안 무섭다 → 관심 소진 생존은 **팀이 개입했을 때만** 거의 일어나게 수치 조정(자연 소진 루프 5회 = 40초 → 시간 만료와 비슷).

## 궁합
- 03 호기심(미끼), 14 숨을 곳(놓아준 뒤 숨기), 07 두 마리(한 마리가 놀면 다른 마리가 온다 — 끔찍하고 웃김), 11 실패(물고 가다 떨어뜨림).
