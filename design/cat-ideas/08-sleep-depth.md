# 08 — 잠의 단계

**한 줄:** 잠은 on/off가 아니다. **얕은 잠 ↔ 깊은 잠**이 파도처럼 오가고, 꼬리·귀·숨소리가 지금 어느 단계인지 알려준다. 잠든 고양이 옆을 지나는 건 타이밍 게임.

## 왜 재밌나
- 지금 Sleep은 "민감도 30%" 한 값. 파동을 주면 **"지금이다!"** 순간이 생긴다 — 은신 게임의 가장 짜릿한 1초.
- 반지(loot_ring)가 고양이 잠자리 2m 안에 스폰된다(docs/10) — 이 안이 반지 플레이를 완성한다.
- 잠꼬대·앞발 꿈틀은 그 자체로 귀엽다(필러 4).

## 플레이어가 겪는 장면
- 잠든 고양이. 꼬리가 **천천히 흔들린다** = 얕은 잠. 배가 크게 오르내리고 **코골이** = 깊은 잠. 팀: "코 골 때 가."
- 깊은 잠 15초 창. 두 마리 쥐가 반지를 향해 기어간다. 8초째 꼬리가 **씰룩** — 얕은 잠으로 바뀌는 예고 3초. 하나는 얼어붙고 하나는 반지를 쥐고 뒤로 긴다.
- 얕은 잠에서 쥐가 달리면 **한쪽 눈만 뜬다**(반쯤 깸, 시야 4m, 3초). 그때 안 움직이면 다시 잔다. 움직이면 완전히 깬다.
- 꿈: 깊은 잠 중 가끔 **앞발을 허우적**(잠꼬대 "냐…"). 소리만 크고 위험 없음 — 초보를 놀라게 하는 장난.

## 규칙 스케치
```
Sleep {
  Light (12~20s): 감각 0.5×, 시야 2m. 꼬리 천천히 흔들림
  → 예고 (3s): 몸 뒤척임, 하품 소리 없음 (깊게 들어감)
  Deep  (10~18s): 감각 0.15×, 시야 0. 코골이. 가끔 꿈(앞발 허우적 1s, 위험 없음)
  → 예고 (3s): 꼬리 씰룩 2회, 귀 돌아감  ← 이게 "나가!" 신호
  → Light
}
HalfAwake (Light 중 자극 ≥ 임계): 한쪽 눈 뜸 3s, 시야 4m 정면만. 추가 자극 없으면 Light로 복귀(민감도 잠시 1.5×), 있으면 Wake → Suspicious
Deep 중 자극 ≥ 임계×2 (접시 깨짐 수준)만 HalfAwake로
```
- 잠자리 주변 **1m는 "체온 반경"**: 들어가면 단계와 무관하게 5초 뒤 HalfAwake(고양이는 옆에 뭐가 있으면 안다). 반지 2m 스폰이라 1m 안쪽은 거의 없음 — 있다면 최고 난도.
- 자는 시간 총량은 성격(01)·루틴(02)이 정하고, 이 안은 **잠 안에서의 파동**만 담당.

## 쥐가 써먹을 틈
- **깊은 잠 창에만 움직인다.** 예고(꼬리 씰룩)를 보면 멈춘다 — 멈추면 안전(얕은 잠 시야 2m).
- 얕은 잠에 걸렸으면 **HalfAwake 3초 동안 얼어붙기**. 정면 4m만 보므로 옆·뒤는 안전.
- 깊은 잠에 접시를 일부러 깨면 HalfAwake로만 간다 → 반대편에서 소음으로 **잠을 흔들어** 팀원이 반지를 빼는 컴비네이션.
- 자는 고양이 **위로 물건을 던져 넘기기**(물리)는 소음만 안 나면 OK — 웃기고 합법.

## 수치 초안
- `SleepLightSeconds 12~20`, `SleepDeepSeconds 10~18`, `SleepForecastSeconds 3`, `SleepLightSense 0.5`, `SleepDeepSense 0.15`, `HalfAwakeSeconds 3`, `HalfAwakeViewDistance 4`, `BodyHeatRadius 1`, `BodyHeatSeconds 5`, `DreamChance 0.2/10s`.

## 구현 메모
- `CatState.Sleep` 내부 서브상태(enum 하나 더, NetworkVariable로 복제 — 클라 연출 필수). `SensitivityMultiplier`를 서브상태별로.
- 연출은 애니 없이도 가능: 꼬리 = 작은 큐브 회전, 코골이 = 사운드, 예고 = 몸 스케일 펄스(그레이박스).
- HUD 의심 표시(SuspicionIndicator)에 잠 단계 아이콘(zZ / z)을 얹으면 시야 밖에서도 읽힌다 — 단 **소리가 먼저**(docs/07 연출 계약).

## 리스크
- 파동 주기를 외우면 반지가 쉬워짐 → 구간 길이 랜덤 폭을 충분히(±4s) + 꿈으로 심리전.
- 예고가 안 보이면 불공평 → 꼬리·귀 연출은 아트 전에 그레이박스라도 반드시.

## 궁합
- 01 성격(게으름뱅이 = Deep 비율 높음), 02 루틴(햇볕 = 이 안의 Light만), 07 두 마리(공동 수면 = 둘의 파동이 어긋나 창이 짧아짐), 11 실패(잠꼬대·침대에서 굴러떨어짐).
