# 04 — 구현된 고양이 한눈에 (2026-09-24, 자율 개발 루프 고양이 1~26)

> 기획(design/cat-ideas, design/cat-design 01~03)에서 **실제로 들어간 것**만. 사양의 정답은 docs/07이고, 기능마다 계획·검증 기록은 `production/plans/cat-NN-*.md`.
> 플레이 테스트 때는 **F3**(고양이 디버그 오버레이)로 고양이 상태·게이지·디렉터를 보면서 확인하면 된다.

## 고양이 상태 한 장 (CatState 19개)

| 상태 | 한 줄 | 쥐가 읽는 법 | 쥐가 쓰는 법 |
|---|---|---|---|
| Sleep | 잠자리에서 얕은 잠↔깊은 잠 파동, 한쪽 눈 뜸 | 꼬리 천천히 / 배 오르내림 / 꼬리 씰룩(곧 얕아짐) | 깊은 잠일 때 지나가기 |
| Patrol | 스팟 그래프 순찰 — 밥·햇볕·그루밍·관찰·화장실·물·잠자리·매복·상자 | 루틴 예고 자막("배 꼬르륵" 등) | 머무는 동안이 안전 |
| Suspicious | 소리·목격 지점 조사 | HUD "?" + 게이지 | 조용히 숨기 |
| Chase | 예측 추격(1s 앞)·오버슛·코너 감속 | HUD "!" (찍혔으면 "!!") | 지그재그, 직선 질주(달리기 6 > 추격 5.5) |
| Capture | 앞발 스윙 0.4s | — | 스윙 끝 전에 비키기 |
| Toy | 잡은 쥐 툭툭·놓아줌·다시 덮침 (동료가 있을 때) | 팀 칩 "잡힘", "풀려났다! 지금 도망쳐!" | 동료가 눈에 띄어 미끼 / 놓아줄 때 2m 도주 |
| Distracted | 유인(털실·캣닢)·뇌물 치즈 먹기 | HUD "냥" | 유인 아이템 |
| Return | 가까운 스팟 복귀 (방금 쓴 행동 스팟 제외) | — | — |
| Search | 놓친 쥐 근처 숨을 곳 킁킁·30% 건드림 | 연노랑·킁킁 | 수색 끊기(미끼) |
| Curious | 굴러가는 물건 앞발로 툭툭 | HUD "냥" | 캔·포도알 굴리기 = 원격 조종 |
| Track | 냄새 자국 따라오기 | 코 킁킁 | 치즈는 마지막에, 웅크리면 자국 간격 2배, 물웅덩이·고양이 침대로 지우기 |
| Blunder | 실수: 미끄러짐·기절·깜짝·비틀·헤어볼·도망(겁쟁이)·기지개(게으름뱅이)·재채기(후추) | 기울기·빙글·펄쩍·휘청·들썩 | 비누·접시·헤어볼·물웅덩이를 추격 경로에 |
| Away | 집주인이 불러 문 밖으로 20~40s | "나비야~" 예고, "고양이가 나갔다!" | 대이동 창 — 돌아올 문은 모름 |
| Fight | 앙숙 두 마리 싸움 15s — 못 듣고 거의 못 봄 | 번쩍·부르르 | 둘을 한 방으로 모으기 |
| Zoomies | 화장실 뒤 10s 우다다(6.5) | "모래 긁는 소리… 곧 우다다!" | 벽에 붙기 |
| Ambush | 60s 매복 — 꼬리만 보임, 2m 덮치기 | 꼬리 + "츄릅" 자막 | 꼬리 보이면 돌아가기 |
| BoxSit | 쥐의 숨을 곳 입구에 앉아 막음, 좁은 시야 | 상자 앞 고양이 | 옆·뒤로 지나가기(정면 3m만 봄) |
| Flank | 짝꿍 협공 — 쥐 2s 앞 지점으로 | 추격색 | 둘이 같은 곳 = 나머지 집이 빔 |
| Respond | 아기 냐앙 → 엄마 달려옴 | "(냐앙!)" 자막 | 아기를 안 건드리기 |

## 검증 방식
- 기능마다: 컴파일 → 에디터 호스트 1인 시나리오(로그·숫자·스크린샷) → 네트워크 변경이면 macOS 빌드 클라 2인 → docs·plan·세션 로그 → 커밋.
- 통합 소크(고양이 20·21): 쥐 자동 배회 + 쥐 짓 6종 + 2마리, 게임 380~514s × 4회 — 예외 0·갇힘 0. 매복 반복 루프 버그 2건을 찾아 고친 뒤 반복 루프 0.
