# 03 — 추천 조합과 구현 순서 초안

축별 후보를 세 단계 세트로 묶었다. 어느 세트든 **그레이박스 데모 스테이지(02-6)에서 검증**하고 나서 방 모듈로 옮긴다.

## 세트 1 — 가벼움 (1~2세션, 데모 최소)
| 축 | 선택 |
|---|---|
| 순찰 | B 스팟 그래프 (Look·Bed·Food만) |
| 감각 | A 단일 게이지 유지 + 움직임 감지(관심은 순찰 중에만) |
| 추격 | A + B 예측 추격 + E 체력 |
| 이동 | A NavMeshAgent |
| 텔레그래프 | 표의 Sleep/Suspicious/Chase/체력 소진 4줄 |
| 맵 | 스팟 3타입 + 쥐 전용 틈 2개 + 어둠 1곳 |
| 아이디어 | 08 잠의 단계(얕/깊 파동), 01 성격 2종(게으름뱅이·사냥꾼) |

효과: 고양이가 "볼일 보러 다니고, 자고, 쫓다가 지치는" 동물이 된다. 반지 플레이가 성립한다.

## 세트 2 — 기본 (추천)
세트 1 +
| 축 | 추가 |
|---|---|
| 순찰 | D 루틴 슬롯(Food·Sun) + 예고음 |
| 감각 | B 이축(의심/관심) + 추정 반경 |
| 추격 | D 수색 |
| 맵 | Box·Ambush·Perch 스팟, 선반 층 Link, 숨을 곳 2개 |

효과: 추격의 결말이 셋(도망/숨기/잡힘), 물리와 고양이가 연결, 맵이 3D로 위험해진다.

## 세트 3 — 풍성 (맵 모듈·아트 뒤)
세트 2 + 순찰 F 하이브리드 완성(관심 주도), 추격 C 차단(2마리), 07 두 마리 관계, 02 루틴 전체, 10 집주인 이벤트, 12 디렉터, 06 냄새.

## 구현 순서 초안 (세트 2 기준, 태스크 단위)
1. **리팩터**: `CatBrain` 수치 접근을 프로필 경유로, 웨이포인트 배열 → `CatSpot` 그래프(방 없는 씬은 씬 전체 = 방 1개). 동작 동일 회귀 확인.
2. **데모 레이아웃 툴**: `Tools/RatGame/Cat/Build Demo Layout` — 02-6 배치 자동 생성.
3. **잠의 단계 + 성격 2종** (cat-ideas 08·01) — 텔레그래프 큐브 포함.
4. **예측 추격 + 체력** — 속도·감속 실험(angularSpeed·acceleration).
5. **이축 감각 + 움직임 감지 + 호기심 Paw** — 유인 3종을 관심 점수로 이식.
6. **추정 반경 + 수색 + 숨을 곳 2종**(신발·상자).
7. **선반 층 + Link 점프 + 착지 소음**, 실패 개그.
8. docs/07·10 개정, 수용 기준 갱신, 2인 검증(에디터 호스트 + 빌드 클라).

각 태스크는 production/plans 형식(목표·근거·현재 코드·설계·테스트)으로 따로 쓴다.

## 결정이 필요한 것
1. 감각을 이축(B)으로 갈지, 단일 게이지에 관심만 "상태"로 둘지 — HUD 표현이 달라진다.
2. 데모 스테이지에 선반 층을 넣을지(Link·2층 NavMesh 작업) — 세트 2의 절반이 여기에 걸린다.
3. 고양이 체력(추격 포기)을 넣을지 — "직선이면 도망친다"는 축과 겹쳐 둘 다 있으면 너무 관대할 수 있다. 하나만 고르거나 체력을 길게.
