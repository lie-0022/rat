# 02 — 맵핑 (고양이와 맵이 맞물리는 방식)

고양이 로직의 절반은 맵이 결정한다. 지금 규약(docs/10)은 `CatWaypoints[] 2~4`, `CatSpawn`, `DarkZones[]`뿐이고, 데모 스테이지엔 그마저 없다. 여기서는 **스팟 카탈로그 → 배치 모델 → 통로 문법 → 안전지대 언어 → 스폰 규칙 → 데모 배치안** 순으로 후보를 둔다.

---

## 1. 스팟 카탈로그 — 맵이 고양이에게 주는 "의미 있는 지점"

웨이포인트(좌표)를 **스팟(좌표 + 타입 + 행동)**으로 바꾼다. 방 모듈이 다는 태그.

| 타입 | 고양이 행동 | 쥐에게 뜻하는 것 | 필수? |
|---|---|---|---|
| `Bed` 잠자리 | Sleep(단계 파동). 반지 스폰 기준점 | 고위험 고수익. 깊은 잠 창 노리기 | 존당 1 |
| `Food` 밥그릇 | 밥 루틴 25s, 청각 0.5× | 밥 시간엔 부엌 절대 금지, 나머지 집 안전 | 부엌 방 |
| `Sun` 창가 | 40s 정지, 창 방향 시야 1.2× | 사실상 반쯤 잠, 창 방향만 조심 | 선택 |
| `Perch` 높은 곳 | 사냥꾼 성격이 30s 관찰, 아래를 봄 | 그 방은 위험, 옆 방은 안전 | 선택 |
| `Ambush` 매복 | 커튼·소파 밑에서 60s 대기(꼬리 노출) | 텔레그래프 보고 우회 | 선택 |
| `Box` 상자 | 들어가 앉기(시야 정면만). 쥐도 숨는 곳 | 방향 퍼즐, 공유 자원 | 선택 |
| `Litter` 화장실 | 12s + zoomies | 광란 이동 경고 | 선택 |
| `Water` 물그릇 | 8s. 엎히면 젖은 바닥 | 발자국·미끄럼 | 선택 |
| `Groom` 그루밍 자리 | 20s, 헤어볼 20% | 안전 창 + 개그 | 선택 |
| `Look` 관찰점 | 통로·문 앞에서 5s 두리번 (일반 웨이포인트 대체) | 통로 감시 | 방당 1~2 |
| `Exit/Entry` | 집주인 부르기 때 퇴장·복귀 문 | 복귀 문 도박 | 존당 1~2 |

- 스팟은 `CatSpot` 컴포넌트(타입 enum, 행동 길이 배율, 방향 트랜스폼 = 보는 방향). 방 모듈의 `CatWaypoints[]`를 `CatSpots[]`로 대체(기존 웨이포인트는 `Look`으로 자동 변환 가능).
- **최소 규약**: 방마다 `Look` 1개 이상, 존마다 `Bed` 1개(반지 규칙), 부엌 테마는 `Food` 1개.

## 2. 배치 모델 — 스팟을 누가 어떻게 놓나

### A. 방 모듈 수동 태그 (현재 규약 확장)
- 모델러/레벨 담당이 방 프리팹에 스팟을 놓는다. ZoneGenerator가 방을 이어 붙이면 스팟도 따라온다.
- 장점: 통제, 의도. 절차 조합(docs/10)과 자연스럽게 맞음. 단점: 방마다 손이 감(4~6방 × 테마 2 = 12방이면 감당됨).

### B. 존 레벨 그래프 자동 연결
- 방들의 스팟을 생성 후 **문 소켓을 거쳐 인접 그래프**로 잇는다(방 내부는 완전 연결, 방 사이는 문). 고양이는 이 그래프 위를 다닌다(순찰 모델 B/F).
- 장점: 방이 어떻게 조합돼도 순찰이 방을 넘나든다(지금은 씬 전체 배열이라 방 개념이 없음). 2마리면 영역 분할이 그래프 컷으로 가능. 단점: 생성 단계 하나 추가.
- 필수에 가까움 — A와 같이 간다.

### C. 자동 히트맵 생성
- 스팟을 사람이 안 놓고, NavMesh 위에서 **문 앞·막다른 곳·전리품 밀집지**를 계산해 Look/Ambush를 자동 배치.
- 장점: 방 데이터 0. 단점: 의도가 없어 밋밋, 디버그 어려움. 그레이박스 초기에만 임시로.

### D. 디자이너 루트(스플라인)
- 방마다 순찰 스플라인. 절차 조합과 상성 나쁨(01-4-D). 비추.

**추천**: A + B. C는 스팟이 없는 방의 폴백(자동 Look 1개).

## 3. 통로 문법 — 누가 어디로 다니나

맵이 "여긴 안전, 여긴 위험"을 말하려면 통로에 **등급**이 있어야 한다. 쥐는 작고 고양이는 크다 — 이게 핵심 자원.

| 등급 | 예 | 쥐 | 고양이 | 표시(그레이박스) |
|---|---|---|---|---|
| 쥐 전용 | 문 밑 틈(높이 0.15), 벽 구멍, 파이프, 선반 뒤 틈 | 웅크려 통과(속도 1.9) | 불가 | 진한 갈색 프레임 |
| 공용 바닥 | 문 열린 통로, 방 바닥 | 자유 | 자유 | 없음 |
| 고양이 전용 | 선반 위 층, 캣타워, 소파 등받이 | 점프로 못 올라감(파쿠르 없음) | NavMeshLink로 점프 | 위층 NavMesh 색 |
| 조건부 | 닫힌 문(고양이가 4s 밀면 열림), 룸바 경로, 물웅덩이 | 통과(소음·미끄럼) | 통과 가능 | 문 색 |

규칙 제안:
- **모든 방에 쥐 전용 통로 최소 1개** — 추격의 탈출구. 없으면 그 방은 "막다른 방"으로 명시(보너스방만 허용).
- 쥐 전용 통로 앞 1m는 **쥐구멍 가치의 함정 자리**(쥐덫 배치 우선 — docs/10 "좁은 통로" 규칙과 일치).
- 고양이 전용 층은 아래 바닥의 **시야 덮개**를 만든다: 위층 고양이는 아래를 보지만(pitch -30°), 선반 바로 밑 그늘(DarkZone)은 못 본다.
- 무거운 물건(Large)은 쥐 전용 통로를 **못 지난다**(폭 0.4 이하) → 대형 운반은 공용 통로 강제 = 협동과 위험이 같은 자리(필러 1·3).

NavMesh 구현: 쥐 전용 통로는 고양이 Agent 반경(0.35)보다 좁게 뚫으면 자동으로 고양이 NavMesh에서 빠진다 — **별도 마스크 없이 지오메트리로 해결**. 위층은 `NavMeshLink`(점프 지점 프리팹에 포함). 룸바 경로는 `NavMeshObstacle` 이동.

## 4. 안전지대 언어 — 쥐가 한눈에 읽는 "여기서 쉬어도 된다"

| 언어 | 규칙 | 시각 |
|---|---|---|
| 어둠(DarkZone) | 시야 거리 50%(기존). 제안: 웅크림+어둠 = 25% | 바닥 톤 어둡게, 볼륨 경계에 먼지 |
| 틈(쥐 전용 통로 안) | 고양이 시야 무효(Linecast 막힘 + 진입 불가) | 프레임 색 |
| 숨을 곳(HideSpot) | 완전/부분 은폐(`cat-ideas/14`) | 신발·상자·커튼 오브젝트 |
| 고양이 냄새(Bed 반경 1.5) | 자기 냄새 덮임 30s(냄새 시스템 있을 때) | 침대 |
| 소음 덮개 | 룸바·TV·싸움 지속음 반경: 발소리 마스킹 | 소리 파문 연출(06) |

원칙: **안전지대는 항상 대가가 있다** — 어둠은 이동이 느림(웅크림), 틈은 대형 불가, 숨을 곳은 나갈 때 소음, 침대는 고양이가 돌아오는 곳.

## 5. 스폰·수량·영역 규칙

- 수량: Zone1 1마리, Zone3+ 2마리(docs/00 유지). 데모 스테이지(단일 맵)는 **1마리 기본, 옵션 2마리**.
- 스폰 위치: `Bed` 스팟(잠에서 시작 — 첫 30초는 관찰 시간, 반지 유혹). 2마리면 두 번째는 `Look`/`Sun`에서 깨어 있는 채로(성격 사냥꾼 우선).
- 영역(2마리): 존 그래프를 문 기준으로 **두 덩어리로 컷**, 각자 자기 덩어리 스팟만 순찰. 추격은 영역 무시. 관계(`cat-ideas/07`)는 컷 경계 방에서 마주치게 설계.
- 반지: `Bed` 반경 2m 고정(docs/10 유지). 추가 제안: `Ambush` 스팟 뒤에도 Special 후보 30%.
- 고양이 없는 방: 존마다 1개 허용(전리품 밀집 "창고"). 대신 그 방으로 가는 통로에 함정 2개.

## 6. 데모 스테이지 배치안 — Stage_Warehouse01 그레이박스

지금은 빈 창고 한 칸. 방 모듈 없이도 **한 씬에 스팟·통로·어둠을 배치**해 01·02를 검증한다.

```
 ┌───────────────────────────────────────────────┐
 │  선반 층(고양이 Perch) ═══════════   [창가 Sun]  │
 │   ▲Link                                        │
 │  [Bed]·반지        ┌─상자 Box─┐     [Look A]    │
 │                    └──────────┘                 │
 │ ▓▓ DarkZone ▓▓          중앙 통로               │
 │ ▓▓ (선반 밑) ▓▓  ◄틈►  ┃  룸바 왕복  ┃  ◄틈►     │
 │                    [Look B]        [Food]·[Water]│
 │  쥐구멍 ◎  ◄쥐 전용 파이프►                     │
 └───────────────────────────────────────────────┘
```
- 스팟 7개: Bed·Sun·Perch·Box·Look×2·Food(+Water). 쥐 전용 통로 3개(틈 2, 파이프 1 — 쥐구멍 직행 파이프는 대형 불가).
- 어둠 1곳(선반 밑), 룸바 1대(조건부 통로), 선반 층 1개(Link 2곳).
- 이 배치로 검증할 것: 순찰이 스팟을 도는가 / 잠 파동에서 반지를 빼는 창이 있는가 / 틈으로 도망치면 추격이 끊기고 수색으로 가는가 / 선반 위 고양이가 아래를 보는가 / 대형이 파이프를 못 지나 공용 통로로 강제되는가.
- 배치는 `Tools/RatGame/Cat/Build Demo Layout` MenuItem으로 자동 생성(큐브·트리거·태그) — 손 배치 최소화.

## 7. 검증 체크리스트 (맵핑 수용 기준 초안)

- [ ] 모든 방에 `Look` ≥1, 쥐 전용 통로 ≥1 (보너스방 제외) — 에디터 검사 툴로 자동 확인
- [ ] 존 그래프가 방 경계를 넘어 연결되고 고양이가 3분 안에 모든 방을 방문
- [ ] 쥐 전용 통로를 고양이 Agent가 경로로 쓰지 않음(NavMesh 검사)
- [ ] 선반 층 Link 점프 성공률 ≥ 95%(실패 개그는 의도된 15%만)
- [ ] 반지가 항상 `Bed` 2m 내, 깊은 잠 창에서 회수 가능
- [ ] 2마리 영역 컷이 존을 반으로 나누고, 경계 방에서만 마주침
- [ ] 룸바 경로 위 대형 운반이 밀리는 상황이 웃김(필러 1) — 플레이테스트 기준
